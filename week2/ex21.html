Frequently Asked Questions

What is the difference between section and article?

An article is self-contained and makes sense outside its page (a blog post, a comment).
A section groups related content that needs surrounding page for context.

Why should I use seamntinc HTML?

Semantic HTML improves:
(1) SEO - search engines understand structure;
(2) Accessibility - schreen readers navigate by landmarks;
(3) MAintainability - code is easier for humans to read.

Key rule to remember

Use semantic elements first. Only fall back to div/span when no semantic element fits.
