📚 Book Search App

Apply everything learned in Weeks 1–6: Semantic HTML · CSS Layout · JS DOM · Fetch API

🎯 What you will build

A book search page that queries the free Open Library API and displays results as styled cards — cover image, title, author, year.

You will build it in 5 guided steps, starting from a blank skeleton and adding one layer at a time. Each step file is already saved on your computer — open it, read the task comment at the top, then add the code.
