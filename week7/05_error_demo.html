The 3 scenarios you must know
✅ Scenario 1: Success (HTTP 200) fetch() resolves normally. res.ok is true. res.status is 200. You can safely call await res.json().
⚠️ Scenario 2: HTTP Error (404, 500, etc.) — THE GOTCHA fetch() STILL RESOLVES (does NOT throw). res.ok is false. res.status is 404 or 500. Your try block keeps running — you MUST manually check if (!res.ok) throw new Error(...) to handle this.
❌ Scenario 3: Network Failure (no internet, bad domain) fetch() REJECTS — it throws a TypeError like "Failed to fetch". This goes directly to your catch block automatically. No need to check res.ok — there is no response object.
The correct pattern to handle all 3
async function loadData(url) { try { const res = await fetch(url); // Handle Scenario 2 — fetch() didn't throw, but status is bad if (!res.ok) throw new Error(`HTTP error: ${res.status}`); const data = await res.json(); render(data); // Scenario 1 — success! } catch (err) { // Catches BOTH: Scenario 2 (manual throw) + Scenario 3 (network failure) showError(err.message); } }
