😂 loadJoke() — step through it

Press Next to advance one line at a time. Each step explains exactly what that line does.

async function loadJoke() {
  const res  = await fetch('https://official-joke-api.appspot.com/random_joke');
  const data = await res.json();
  document.getElementById('setup').textContent = data.setup;
  document.getElementById('punchline').textContent = data.punchline;
}

👤 loadUser() — step through it

This example fetches user data from a test API. Same pattern, different data.

async function loadUser() {
  const res  = await fetch('https://jsonplaceholder.typicode.com/users/1');
  const user = await res.json();
  console.log('Name:', user.name);   // → "Leanne Graham"
  console.log('Email:', user.email);  // → "Sincere@april.biz"
}
