fetch · async · await

😂 Click the button to fetch a real joke

Data is loaded live from the internet. Every click gets a different joke.

What just happened?
When you clicked the button, the function loadJoke() ran. It used fetch() to send a request to official-joke-api.appspot.com — a server that lives on the internet. A fraction of a second later, the server replied with JSON data containing a joke. JavaScript put that data onto the page. The page never reloaded.
The complete code powering this demo
// The URL of the joke API const API = 'https://official-joke-api.appspot.com/random_joke'; const FALLBACK = { setup: 'Why do programmers prefer dark mode?', punchline: 'Light attracts bugs! 🐛', type: 'demo' }; let count = 0; async function loadJoke() { // Disable button while loading document.getElementById('btn').disabled = true; // Show the output area and loading message document.getElementById('out').style.display = 'block'; document.getElementById('loading').style.display = 'block'; document.getElementById('joke').style.display = 'none'; document.getElementById('errMsg').style.display = 'none'; try { // Step 1: Send request, wait for RESPONSE (headers) const res = await fetch(API); // Step 2: Wait for BODY and parse as JSON const data = res.ok ? await res.json() : FALLBACK; // Step 3: Put the data on the page (DOM manipulation) document.getElementById('setup').textContent = data.setup; document.getElementById('punchline').textContent = data.punchline; document.getElementById('meta').textContent = `Type: ${data.type} | Source: joke API ✓`; document.getElementById('joke').style.display = 'block'; count++; } catch (err) { // Network failure (no internet) → show fallback document.getElementById('setup').textContent = FALLBACK.setup; document.getElementById('punchline').textContent = FALLBACK.punchline; document.getElementById('meta').textContent = '(demo fallback — no internet?)'; document.getElementById('joke').style.display = 'block'; count++; } finally { // ALWAYS: hide loading, re-enable button, update count document.getElementById('loading').style.display = 'none'; document.getElementById('btn').disabled = false; document.getElementById('btn').textContent = 'Load Another Joke'; document.getElementById('cnt').style.display = 'inline-block'; document.getElementById('count').textContent = count; } }
Key concepts in this demo
async function — The word async before function enables the await keyword inside. Without it, await causes a syntax error.
Two awaits — The first await fetch() waits for the server's response headers. The second await res.json() waits for the response body to be fully downloaded and parsed.
finally block — Runs whether the request succeeded or failed. Perfect for re-enabling buttons and hiding loading spinners.
