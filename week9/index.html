Student Registration Form Validation

Build a fully validated student registration form — HTML5 attrs · CSS pseudo-classes · JS validation · Accessibility

What you will build

A Student Registration Form that validates all fields in real time before allowing submission — student ID format, email, password strength, confirm-password match, and team selection.

You will build it in 6 guided steps, adding one layer at a time: HTML structure → CSS → basic JS → live feedback → regex validation → accessibility. Each step file is already saved on your computer — open it, read the task comment at the top, then add the code.
Guided Steps — work through these in order
STEP 1

HTML Structure

Write the registration form skeleton: fieldsets, labels, inputs, select, and submit button. No CSS yet.

fieldset label/input select
STEP 2

CSS Styling

Style the form with CSS variables. Use :valid and :invalid pseudo-classes for live color feedback.

CSS Variables :valid/:invalid :focus
STEP 3

JS Basic Validation

Intercept the submit event with e.preventDefault(). Read field values and show them in an alert.

addEventListener preventDefault .value
STEP 4

Real-time Feedback

Show error messages as the user types using 'input' events. Clear errors when the field becomes valid.

input event textContent display:none
STEP 5

Advanced Validation

Add regex for student ID (9 digits), email format, and password-confirm match check.

RegExp.test() password match pattern
STEP 6 · BONUS

Accessibility

Wire aria-describedby, aria-invalid, and role="alert" so screen readers announce errors.

aria-describedby aria-invalid role=alert

CHEAT SHEET

HTML5 Validation API

Quick reference card: all HTML5 validation attributes, CSS pseudo-classes, and key JS Constraint Validation API methods.

required pattern minlength
Key concepts this week: required, pattern, minlength, type="email" — HTML5 built-in validation — plus e.preventDefault() on submit to run your own JS checks before allowing the form to go through.

Error spans are hidden by default (display:none) and revealed by JS setting textContent and toggling a class. The submit button is disabled until every field passes validation.
