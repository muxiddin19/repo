WEEK 9 · FRIDAY · PRACTICAL LAB

Deploy to GitHub Pages

Take your Book Search App from your computer to the internet — live, shareable, and free — using Git and GitHub Pages.

What you will accomplish today

1Set up Git on your computer and configure your identity
2Turn your Book Search project folder into a git repository
3Create a remote repository on GitHub called webpro-booksearch
4Push your code to GitHub with git push
5Enable GitHub Pages so your app is live at https://username.github.io/webpro-booksearch
6Verify the live site and fix common deployment problems

Guided steps — work through these in order
Step 1

Create a GitHub Account & Install Git

Sign up at github.com, download and install Git, then set your name and email for commits.

git --versiongit config
Step 2

Initialize Your Local Repository

Open your Book Search project folder in the terminal. Run git init, stage all files, and make your first commit.

git initgit addgit commit
Step 3

Create a GitHub Repository

Create a new public repository on GitHub named webpro-booksearch. Do NOT add a README yet.

GitHub.comNew repository
Step 4

Connect & Push to GitHub

Link your local repo to GitHub with git remote add, then push your commits to the cloud.

git remotegit push
Step 5

Enable GitHub Pages

In your repository Settings, turn on GitHub Pages. Choose the main branch and / (root) folder. Save and wait.

Settings → PagesLive URL
Step 6

Verify & Troubleshoot

Open your live URL in an incognito window. Debug common issues: missing index.html, wrong branch, broken paths.

TroubleshootDevTools
