All Commands in Order

Every terminal command you need to deploy your Book Search App to GitHub Pages — from zero to live URL.

0
Prerequisites — one-time setup
Do this once on a new computer
terminal # Verify Git is installed $ git --version git version 2.47.0 # Set your identity (use the email from your GitHub account) $ git config --global user.name "Your Name" $ git config --global user.email "youremail@example.com" # Verify $ git config --global user.name $ git config --global user.email
Already done? Skip Phase 0 — your identity is stored globally and applies to every project.
1
Initialize Your Local Repository
Run once per project, inside the project folder
terminal # Navigate to your project folder first, then: # Initialize Git in this folder $ git init Initialized empty Git repository in .../webpro-booksearch/.git/ # Stage all files $ git add . # Verify what is staged $ git status On branch master Changes to be committed: new file: index.html new file: script.js new file: style.css # Create the first commit $ git commit -m "first commit: add Book Search App" [master (root-commit) a1b2c3d] first commit: add Book Search App 3 files changed, 87 insertions(+)
2
Create the GitHub Repository
Done on github.com — no terminal commands
  1. Go to github.com → click + → New repository
  2. Name: webpro-booksearch   Visibility: Public
  3. Leave all "Initialize" checkboxes unchecked
  4. Click Create repository
  5. Copy the HTTPS URL shown: https://github.com/your-username/webpro-booksearch.git
3
Connect Local Repo to GitHub & Push
Run once per project
terminal # Add GitHub as the remote (paste YOUR URL from Step 2) $ git remote add origin https://github.com/your-username/webpro-booksearch.git # Rename the local branch to 'main' $ git branch -M main # Push commits to GitHub and set tracking branch $ git push -u origin main Enumerating objects: 5, done. To https://github.com/your-username/webpro-booksearch.git * [new branch] main -> main
Authentication: A browser window should open asking you to sign in to GitHub. After signing in, return to the terminal. If it asks for a password directly, enter a Personal Access Token (not your login password).
4
Enable GitHub Pages
Done on github.com — no terminal commands
  1. Open your repository on GitHub
  2. Click the Settings tab
  3. In the left sidebar, click Pages
  4. Under Source → Branch: select main   Folder: select / (root)
  5. Click Save
  6. Wait ~60 seconds, then refresh the Settings → Pages page
  7. Your live URL appears: https://your-username.github.io/webpro-booksearch
5
Update Your Live Site (repeat each time)
After any code change
terminal # Stage your changes $ git add . # Commit with a descriptive message $ git commit -m "add loading spinner" # Push to GitHub — Pages rebuilds in ~60 seconds $ git push
Hard-refresh your browser after pushing to see the update: Ctrl+Shift+R (Windows/Linux) or Cmd+Shift+R (Mac).

Git Command Quick Reference
The commands you will use most often
Command What it does
git statusShow which files have changed, are staged, or are untracked
git add .Stage all changes in the current folder
git add filenameStage one specific file
git commit -m "msg"Save a snapshot of staged files with a message
git log --onelineList all commits (short format), newest first
git diffShow unstaged changes (what changed since last add)
git pushUpload new commits to GitHub (after first push setup)
git pullDownload and merge changes from GitHub into your local repo
git remote -vShow the remote connections for this repo
git branchList local branches (the * shows the current branch)
