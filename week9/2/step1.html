Create a GitHub Account & Install Git

Before we can deploy anything, you need a GitHub account and Git installed on your computer.

? Why do we need Git and GitHub?

Git is version-control software that runs on your computer. It tracks every change you make to your code so you can always go back to a previous version.

GitHub is a website that stores your Git repositories in the cloud. GitHub Pages is a free feature that turns any repository into a live website — no server required.

Git runs locally GitHub is the cloud backup GitHub Pages = free hosting

A Create a GitHub Account

1
Go to github.com and click Sign up.
2
Enter your email address and create a password. Choose a username — this will appear in your public URL: https://USERNAME.github.io/webpro-booksearch
3
Verify your email address when GitHub sends the confirmation email.
4
You can skip the "personalization" questions by clicking Skip personalization.
Already have a GitHub account? Skip this section — go straight to installing Git below.

B Install Git

1
Go to git-scm.com/download/win — the download starts automatically.
2
Run the installer. Click Next through every screen — the defaults are fine. On the "Adjusting your PATH" screen keep "Git from the command line and also from 3rd-party software" selected.
3
On the "Choosing the default branch name" screen, select Override to 'main' if given the option.
4
Finish the installer. Open a new Command Prompt or PowerShell window and verify:
terminal $ git --version # Expected output: git version 2.47.0.windows.2 (or similar)
If git --version shows an error, close all terminal windows and open a fresh one — the PATH update only takes effect in new windows.
1
Open Terminal (press Cmd+Space, type "Terminal", press Enter).
2
Type the command below and press Enter:
Terminal $ git --version
3
If Git is not installed, macOS will pop up a dialog offering to install Xcode Command Line Tools. Click Install and wait — this takes a few minutes.
4
Alternatively, install via Homebrew: brew install git

C Set Your Git Identity

Git needs to know your name and email so every commit is signed with your identity. Run these two commands — replace the values with your own information.

terminal $ git config --global user.name "Your Name" $ git config --global user.email "youremail@example.com"

Verify the settings were saved:

terminal $ git config --global user.name Your Name $ git config --global user.email youremail@example.com
Use the same email as your GitHub account. GitHub uses this to link commits to your profile.
