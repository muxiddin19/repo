Create a GitHub Repository

Create an empty repository on GitHub called webpro-booksearch — this is where your code will live in the cloud.

? What is a Remote Repository?

So far your Git history only exists on your computer (the "local" repository). A remote repository on GitHub is a copy stored in the cloud. Pushing to it means your code is backed up and accessible to anyone with the link.

GitHub Pages then reads your repository and serves it as a website — automatically.

A Create the Repository on GitHub

1
Log in to github.com. Click the + button in the top-right corner, then choose New repository.
2
Fill in the form exactly as shown below:
Create a new repository
your-username / webpro-booksearch
Book Search App — Web Programming Week 7
Public
Anyone on the internet can see this repository. Required for GitHub Pages on free accounts.
Private
Add a README file — leave this unchecked
If you add a README here, GitHub creates a commit that conflicts with your local history. Leave all "Initialize" options unchecked — your local repo already has its first commit.
Create repository
Do NOT check "Add a README file." Do not choose a .gitignore template or a license. Leave everything in the "Initialize" section unchecked — you will push your own first commit from your computer.

B Copy Your Repository URL

After clicking Create repository, GitHub shows a "Quick setup" page. Copy the HTTPS URL — you will need it in the next step.

Your repository URL will look like this:
https://github.com/your-username/webpro-booksearch.git
1
Make sure HTTPS is selected (not SSH) — it is the default and easier to use without extra setup.
2
Click the copy icon next to the URL, or select all the text and copy it. Keep it handy — you will paste it into the terminal in Step 4.
The URL format is always: https://github.com/USERNAME/REPONAME.git
