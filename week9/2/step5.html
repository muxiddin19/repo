Enable GitHub Pages

Turn on the Pages feature in your repository settings. GitHub will build and host your site automatically.

? How GitHub Pages Works

GitHub Pages is a free hosting service built into GitHub. When you enable it, GitHub reads your repository's files and serves them as a website at a public URL — no server or hosting account needed.

You simply point Pages at a branch and a folder, and every time you push new commits, the site updates within about 60 seconds.

GitHub Pages serves static files only (HTML, CSS, JavaScript, images). This is perfect for your Book Search App because it runs entirely in the browser using the Fetch API.

A Navigate to Repository Settings → Pages

1
Open your repository on GitHub: https://github.com/your-username/webpro-booksearch
2
Click the Settings tab at the top of the repository (the gear icon at the far right of the tabs).
3
In the left sidebar, scroll down and click Pages.

B Configure the Source

1
Under Build and deployment → Source, make sure Deploy from a branch is selected.
2
Under Branch, click the first dropdown and select main.
3
Click the second dropdown (folder) and select / (root). This tells GitHub Pages to look for your index.html in the root of the repository.
4
Click Save.
Folder selection matters: If you select /docs instead of / (root), your index.html must be inside a folder named docs. Keep it at root for this project.

C Wait for the Build

⏱

Wait about 60 seconds. GitHub needs to build and deploy your site after you click Save.

You can watch the progress: go to the Actions tab of your repository. A yellow spinning dot means "building" — a green checkmark means "done".

1
After 60 seconds, refresh the Settings → Pages page.
2
A green banner will appear at the top of the Pages settings with the text "Your site is live at" followed by your URL.

D Your Live URL

GitHub Pages constructs your URL from your username and repository name:

Your live Book Search App is at:

https://your-username.github.io/webpro-booksearch
1
Click the link on the Settings → Pages page, or type the URL above (with your actual username) into your browser.
2
If it shows a 404 error, wait another 30 seconds and refresh — GitHub Pages may still be building.
3
If it still does not work after 2 minutes, go to Step 6 — Verify & Troubleshoot.
Congratulations! Your Book Search App is now live on the internet. Anyone in the world can visit your URL and use it. Share it with your classmates!
