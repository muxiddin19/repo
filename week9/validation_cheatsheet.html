HTML5 Form Validation Cheat Sheet

K0126002 Web Programming · Gachon University 2026 Fall

HTML5 Validation Attributes
Attribute Example What it does
required <input required> Field cannot be empty. Browser blocks submit and shows a tooltip.
type="email" <input type="email"> Browser validates basic email format (must contain @). Mobile shows email keyboard.
type="number" <input type="number" min="1" max="100"> Accepts only numbers. min / max constrain the range.
minlength <input minlength="8"> Minimum number of characters required.
maxlength <input maxlength="50"> Maximum characters allowed (blocks typing past the limit).
pattern <input pattern="\d{9}"> Regex that the entire value must match. Write the pattern without the / / delimiters.
min / max <input type="date" min="2024-01-01"> Works on number, date, range. Prevents values outside the range.
step <input type="number" step="0.01"> Only multiples of this value are valid (e.g., cents for a price).
novalidate <form novalidate> Turns OFF browser's built-in validation on the form. Use when you want to handle everything with JS.
Tip: pattern on <input type="text"> for student ID: pattern="\d{9}" — but you still need JS to show a custom error message, because the browser tooltip is hard to style.
CSS Pseudo-classes
Selector Matches when
:valid Input passes all its validation constraints
:invalid Input fails one or more constraints
:required Input has the required attribute
:optional Input does NOT have required
:focus Input currently has keyboard focus
:placeholder-shown Placeholder text is visible (field is empty)
:not(:placeholder-shown) User has typed something (field is not empty)
:disabled Input has the disabled attribute
Pattern: Avoid painting red before the user types. Use
input:not(:placeholder-shown):invalid { border-color: red; }
JS Constraint Validation API
Property / Method Returns / Does
input.validity ValidityState object with boolean flags
.validity.valid true if all constraints pass
.validity.valueMissing true if required and empty
.validity.tooShort true if below minlength
.validity.patternMismatch true if value fails pattern
.validity.typeMismatch true if type=email/url format fails
.checkValidity() Returns true/false, fires invalid event
.reportValidity() Same as checkValidity + shows browser tooltip
.setCustomValidity(msg) Set custom error message ("" to clear)
Key JavaScript Patterns
// 1. Prevent default submit & read values
form.addEventListener('submit', function(e) {
  e.preventDefault();                        // stop page reload
  const val = input.value.trim();
});

// 2. Real-time feedback on every keystroke
input.addEventListener('input', function() {
  const val = input.value.trim();
  if (val === '') { showError('Required'); }
  else            { clearError(); }
});

// 3. Regex — student ID (exactly 9 digits)
const STUDENT_ID_RE = /^\d{9}$/;
if (!STUDENT_ID_RE.test(val)) { showError('Must be 9 digits'); }

// 4. Regex — email format
const EMAIL_RE = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
if (!EMAIL_RE.test(val)) { showError('Invalid email'); }

// 5. Password match check
if (pw2Input.value !== pwInput.value) {
  showError('Passwords do not match');
}

// 6. Show / hide error helper
function showError(input, spanId, msg) {
  document.getElementById(spanId).textContent = msg;
  document.getElementById(spanId).classList.add('visible');
  input.setAttribute('aria-invalid', 'true');
}
function clearError(input, spanId) {
  document.getElementById(spanId).textContent = '';
  document.getElementById(spanId).classList.remove('visible');
  input.setAttribute('aria-invalid', 'false');
}
Accessibility Attributes
Attribute / Role Example Purpose
aria-describedby <input aria-describedby="id-error"> Links input to its error span. Screen reader reads the error text after the label.
aria-invalid input.setAttribute('aria-invalid','true') Signals to AT that the field has a validation error.
role="alert" <span role="alert"></span> Any new text injected into this element is immediately announced by the screen reader.
aria-live="polite" <div aria-live="polite"> Alternative to role="alert". Announces changes politely (waits for current speech to finish).
aria-required="true" <input aria-required="true"> Tells AT the field is required (redundant when required is present, but explicit).
element.focus() firstInvalidEl.focus() On invalid submit, move keyboard focus to the first invalid field so users don't have to find it.
Regex Quick Reference
Pattern Matches Use case
/^\d{9}$/ Exactly 9 digits (0-9) Student ID (학번)
/^[^\s@]+@[^\s@]+\.[^\s@]+$/ Basic email: x@y.z Email validation
/^.{8,}$/ Any 8+ characters Minimum password length
/^[A-Za-z\s]+$/ Letters and spaces only Name fields (ASCII only)
/^\d{10,11}$/ 10 or 11 digits Korean phone numbers
/^(?=.*[A-Z])(?=.*\d).{8,}$/ 8+ chars, 1 uppercase, 1 digit Strong password
Regex syntax reminder: ^ = start of string  •  $ = end of string  •  \d = any digit  •  {n} = exactly n times  •  [^\s@] = any char that is NOT a space or @  •  + = one or more  •  Use regex.test(value) to check if a string matches.
