01

What is CSS?

Q1

CSS stands for Cascading Style Sheets. While HTML describes the structure of a page (headings, paragraphs, lists), CSS controls its visual appearance: colours, fonts, spacing, layout, and animation. Without CSS every web page would look like a plain text document — black text on white, no styling at all.

The word Cascading is the most important part of the name. When multiple CSS rules target the same element, a set of rules called the cascade determines which one wins based on specificity and order. You will learn the cascade rules in topic 22–23. CSS is the second language you learn in this course; HTML must come first because CSS has nothing to style without it.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>CSS Demo</title> <style> /* Without this CSS block the page looks plain */ body { font-family: sans-serif; background: #f0f9ff; color: #1e293b; } h1 { color: #15803d; font-size: 2rem; } p { max-width: 60ch; line-height: 1.7; } </style> </head> <body> <h1>Hello, CSS!</h1> <p>This heading is green and the background is light blue — all controlled by CSS, not HTML.</p> </body> </html>

Key Points

  • CSS = Cascading Style Sheets — controls appearance, not structure.
  • HTML is structure; CSS is style; JavaScript is behaviour.
  • 'Cascading' = rules with higher specificity or later position win.
  • CSS3 is the current standard, split into separate modules.
02

Three Ways to Add CSS

Q2 Q3

There are exactly three ways to connect CSS to HTML. External stylesheet: write CSS in a separate .css file and link it with <link rel="stylesheet" href="style.css"> inside <head>. Internal (embedded): write CSS inside a <style> block in <head>. Inline: write CSS directly on an element with the style attribute.

For any website larger than one page, external stylesheets are always best: one CSS file styles every page — change the file and every page updates instantly. Internal styles are useful for quick demos or email HTML. Inline styles should only be used as a last resort (e.g., dynamically set by JavaScript) because they are almost impossible to override and mix structure with style.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <!-- METHOD 1: External stylesheet (BEST for real projects) --> <link rel="stylesheet" href="style.css"> <!-- METHOD 2: Internal <style> block (good for single pages / demos) --> <style> h2 { color: #15803d; } p { font-family: Georgia, serif; } </style> </head> <body> <!-- METHOD 3: Inline style attribute (avoid — hard to maintain) --> <p style="color: red; font-size: 20px;">Inline styled paragraph.</p> <h2>Internal style heading</h2> <p>Internal style paragraph.</p> </body> </html>

Key Points

  • External .css file — best: reuse across pages, change once to update all.
  • Internal <style> block — acceptable for demos and single pages.
  • Inline style='' — last resort; mixes structure with presentation.
  • All three can co-exist but external is the professional standard.
03

CSS Syntax

Q4

Every CSS rule follows the same structure: selector { property: value; }. The selector targets which HTML element(s) to style. The property names what to change (e.g. color, font-size). The value sets how much or what (e.g. red, 18px). The property and value are separated by a colon and the declaration ends with a semicolon.

A rule block can contain many property-value pairs, each on its own line for readability. Forgetting the colon (not an equals sign!) or the semicolon between rules are the two most common CSS syntax errors. CSS is case-insensitive for property names and most values, but it is good practice to write them in lowercase.

HTML / CSS
/* Basic CSS rule anatomy */ selector { property: value; /* one declaration */ property: value; /* another declaration */ } /* Real examples */ h1 { color: #15803d; /* text colour */ font-size: 2rem; /* size */ font-weight: bold; /* weight */ text-align: center; /* alignment */ } p { line-height: 1.7; /* space between lines */ max-width: 65ch; /* column width */ } /* Common mistakes */ /* h1 { color = red } ← = instead of : → WRONG */ /* h1 { color: red } ← missing semicolon → risky */

Key Points

  • Syntax: selector { property: value; }
  • Colon (:) between property and value — NOT equals sign (=).
  • Semicolon (;) after every declaration.
  • One block can hold many declarations — one per line for readability.
04

The Universal Selector (*)

Q5

The universal selector * matches every single element on the page. It is most commonly used in a CSS reset at the top of a stylesheet to remove browser default margins and set box-sizing: border-box — a setting that makes layout calculations much more predictable.

Using * for general styling (e.g. * { color: red; }) is a bad practice because it overrides every element indiscriminately and can harm performance. In the box-model reset below, it is an accepted professional pattern and appears in virtually every modern CSS framework.

HTML / CSS
/* ── The classic CSS reset using * ── */ *, *::before, *::after { box-sizing: border-box; /* padding/border included in width — very useful */ margin: 0; padding: 0; } /* Now you add styles on top cleanly */ body { font-family: 'Inter', sans-serif; line-height: 1.6; background: #f8fafc; color: #1e293b; } /* Avoid this — affects every element */ /* * { color: blue; } ← too aggressive! */

Key Points

  • * = universal selector — targets every element on the page.
  • Most useful in a CSS reset: *, *::before, *::after { box-sizing: border-box; }
  • box-sizing: border-box makes padding included in the element's width.
  • Avoid using * for general styling — it overrides everything.
05

ID Selector (#id)

Q6

An ID selector begins with a # (hash). It matches the one element on the page with a matching id attribute. Because IDs must be unique per page (only one element can have a given id), ID selectors apply to exactly one element.

ID selectors have very high specificity — they beat class and type selectors in a specificity conflict. This makes them hard to override later, which is why many developers prefer class selectors for styling and reserve IDs for JavaScript targeting and in-page anchor links.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* ID selector — targets the ONE element with id="main-title" */ #main-title { color: #15803d; font-size: 2.5rem; border-left: 5px solid #10B981; padding-left: 12px; } #hero-banner { background: #ecfdf5; padding: 40px; border-radius: 12px; } </style> </head> <body> <div id="hero-banner"> <h1 id="main-title">CSS Introduction</h1> <p>This heading is styled via its unique id.</p> </div> </body> </html>

Key Points

  • # prefix: #idName targets the element with id='idName'.
  • ID must be unique — only ONE element per page can have a given id.
  • High specificity — harder to override than class or type selectors.
  • Prefer classes for styling; reserve IDs for JS and anchor links.
06

Class Selector (.class)

Q7

A class selector begins with a . (dot/period). It matches all elements that have the matching class attribute. The same class can be applied to many elements, and one element can have multiple classes: class="card featured large".

Classes are the primary tool for CSS styling in professional development. Write a CSS class once, reuse it on any element. This is the basis of CSS frameworks like Bootstrap and Tailwind. Naming conventions: use lowercase kebab-case (.main-nav, .product-card).

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .card { border: 1px solid #e2e8f0; border-radius: 8px; padding: 20px; margin: 10px; } .featured { /* extra class layered on top */ border-color: #10B981; background: #ecfdf5; } .large { font-size: 1.25rem; } </style> </head> <body> <div class="card">Plain card</div> <div class="card featured">Featured card (two classes)</div> <div class="card featured large">Featured + large (three classes)</div> </body> </html>

Key Points

  • . prefix: .className targets all elements with that class.
  • Reusable — same class can be applied to many elements.
  • One element can carry multiple classes (space-separated).
  • Classes are the primary styling tool in professional CSS.
07

Type / Element Selector

Q8

A type selector (also called element selector) matches every HTML element of that tag name. Writing p { color: navy; } applies to every <p> on the page. These selectors set baseline styles for the whole site.

Type selectors have the lowest specificity of the three basic selector types (lower than class and ID). This is intentional: you set a sensible default with a type selector, then refine it for specific elements using classes or IDs. Combining selectors is also common: p.intro targets only paragraphs with class intro.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Type selectors — apply to every element of that type */ h1 { color: #15803d; } h2 { color: #1d4ed8; font-size: 1.4rem; } p { font-size: 1rem; line-height: 1.7; color: #334155; } a { color: #10B981; text-decoration: none; } a:hover { text-decoration: underline; } /* Combination: only <p> with class="lead" */ p.lead { font-size: 1.2rem; font-weight: 500; } </style> </head> <body> <h1>Main Heading — green</h1> <h2>Sub Heading — blue</h2> <p class="lead">Lead paragraph (larger).</p> <p>Normal paragraph. <a href="#">A link.</a></p> </body> </html>

Key Points

  • Type selector: just the tag name — p, h1, a, div.
  • Targets EVERY element of that tag on the page.
  • Lowest specificity — easily overridden by classes and IDs.
  • Combine: p.intro targets only <p class='intro'> elements.
08

The color Property

Q9

The CSS color property sets the foreground (text) colour of an element. It accepts named colours (red, navy, tomato), hex codes (#15803d), RGB values (rgb(21,128,61)), and HSL values (hsl(142,72%,29%)). The property is inherited — setting color on body applies to all text on the page unless overridden.

Note: color only affects text and the currentColor of borders/outlines — it does not change the background. For background colour, use background-color (topic 9). Korean students often confuse these two. Remember: color = text; background-color = fill behind text.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> body { color: #1e293b; } /* all text inherits this */ .red { color: red; } /* named colour */ .green { color: #15803d; } /* hex colour */ .blue { color: rgb(29, 78, 216); } /* rgb() */ .purple { color: hsl(262, 83%, 58%); }/* hsl() */ .muted { color: #94a3b8; } /* muted/grey */ /* color on a heading — children inherit it */ h2 { color: #10B981; } </style> </head> <body> <h2>All these paragraphs use color:</h2> <p class="red">Named colour: red</p> <p class="green">Hex colour: #15803d</p> <p class="blue">RGB colour: rgb(29, 78, 216)</p> <p class="purple">HSL colour: hsl(262, 83%, 58%)</p> <p class="muted">Muted grey text</p> </body> </html>

Key Points

  • color = foreground (TEXT) colour — not background.
  • Accepts: named (red), hex (#ff0000), rgb(), hsl().
  • color is inherited — set on body to apply to all text.
  • To change background: use background-color (different property).
09

background-color Property

Q10

The background-color property fills the area behind an element's content with a colour. It accepts the same colour formats as the color property: named colours, hex codes, rgb(), and hsl(). The default value is transparent, which lets the parent's background show through.

Pairing color and background-color correctly is crucial for accessibility. The contrast ratio between text and background must be at least 4.5:1 (WCAG AA standard). Very light text on white or very dark text on black always fails. Tools like the WebAIM Contrast Checker help verify this.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .banner { background-color: #15803d; color: white; padding: 20px 30px; border-radius: 8px; } .warning { background-color: #fef3c7; /* amber-50 */ color: #92400e; /* amber-800 */ padding: 12px 16px; border-left: 4px solid #f59e0b; } .dark-card { background-color: #1e293b; color: #e2e8f0; padding: 20px; } </style> </head> <body> <div class="banner">Green banner — white text (high contrast)</div> <br> <div class="warning">⚠ Warning box — amber background</div> <br> <div class="dark-card">Dark card — light text</div> </body> </html>

Key Points

  • background-color fills the area behind an element's content.
  • Default is transparent — parent background shows through.
  • Same colour formats as color: named, hex, rgb(), hsl().
  • Ensure contrast ratio ≥ 4.5:1 for readable text (WCAG AA).
10

Hex Color Codes

Q11

A hex colour code starts with # followed by six hexadecimal digits (0–9, A–F): #RRGGBB. The first two digits set the Red channel, the next two Green, and the last two Blue. Each channel ranges from 00 (none) to FF (maximum). So #FF0000 = pure red, #00FF00 = pure green, #0000FF = pure blue.

A 3-digit shorthand exists when each pair repeats: #RGB. So #F00 = #FF0000 (red), #0F0 = #00FF00 (green), #FFF = #FFFFFF (white). Hex codes are the most widely used CSS colour format — every design tool (Figma, Photoshop, Canva) exports colours as hex.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* #RRGGBB — Red / Green / Blue, each 00–FF */ .red { background-color: #FF0000; } /* pure red (FF,00,00) */ .green { background-color: #00FF00; } /* pure green (00,FF,00) */ .blue { background-color: #0000FF; color: white; } /* pure blue */ .white { background-color: #FFFFFF; border: 1px solid #ccc; } .black { background-color: #000000; color: white; } .custom { background-color: #10B981; color: white; } /* emerald */ /* Shorthand — only when each pair repeats */ .short-red { background-color: #F00; } /* same as #FF0000 */ div { padding: 8px 16px; margin: 4px; display: inline-block; } </style> </head> <body> <div class="red">#FF0000 Red</div> <div class="green">#00FF00 Green</div> <div class="blue">#0000FF Blue</div> <div class="white">#FFFFFF White</div> <div class="black">#000000 Black</div> <div class="custom">#10B981 Emerald</div> <div class="short-red">#F00 (shorthand)</div> </body> </html>

Key Points

  • #RRGGBB — 6 hex digits for Red, Green, Blue (each 00–FF).
  • #FF0000 = red, #00FF00 = green, #0000FF = blue, #FFFFFF = white.
  • Shorthand #RGB when each pair repeats: #F00 = #FF0000.
  • Most common format — all design tools export hex codes.
11

RGB Color Values

Q12

The rgb() function takes three numbers (0–255) for Red, Green, and Blue: rgb(255, 0, 0) is pure red. It produces the same colours as hex codes but is easier to read and adjust: incrementing the red value slightly is more intuitive than guessing hex digits.

The rgba() function adds a fourth parameter — alpha (transparency) from 0 (fully transparent) to 1 (fully opaque). Modern CSS also supports a one-function form: rgb(255 0 0 / 50%) without commas. Use rgba() to create translucent overlays, subtle shadows, and glassmorphism effects.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* rgb(Red 0-255, Green 0-255, Blue 0-255) */ .ex1 { background-color: rgb(255, 0, 0); color: white; } /* red */ .ex2 { background-color: rgb(21, 128, 61); color: white; } /* green*/ .ex3 { background-color: rgb(29, 78, 216); color: white; } /* blue */ .ex4 { background-color: rgb(100, 100, 100); color: white; }/* grey*/ /* rgba — 4th value = alpha (opacity 0.0–1.0) */ .overlay { background-color: rgba(0, 0, 0, 0.5); /* 50% transparent black */ color: white; padding: 20px; } .glass { background-color: rgba(21, 128, 61, 0.15); /* translucent green */ border: 1px solid rgba(21, 128, 61, 0.4); padding: 12px; } div { padding: 8px 16px; margin: 6px; } </style> </head> <body> <div class="ex1">rgb(255, 0, 0) — Red</div> <div class="ex2">rgb(21, 128, 61) — Green</div> <div class="ex3">rgb(29, 78, 216) — Blue</div> <div class="ex4">rgb(100, 100, 100) — Grey</div> <div class="overlay">rgba(0,0,0,0.5) — 50% black overlay</div> <div class="glass">rgba green 15% — glassmorphism card</div> </body> </html>

Key Points

  • rgb(R, G, B) — three values 0–255 for Red, Green, Blue.
  • rgb(255,0,0) = red; rgb(0,0,0) = black; rgb(255,255,255) = white.
  • rgba() adds alpha (opacity): 0 = invisible, 1 = fully opaque.
  • Use rgba() for overlays, shadows, and translucent effects.
12

font-size Property

Q13

The font-size property sets how large text appears. Units: px (pixels, fixed), rem (relative to root <html> font-size, typically 16px — so 1rem = 16px), em (relative to parent element's font-size), and % (percent of parent). Rem is the preferred unit for font sizes in modern development because it respects the user's browser font-size preference.

Avoid setting font-size in px on the root html element — this breaks user font-size preferences (an accessibility concern). Instead set html { font-size: 100%; } (keeping the browser default) and use rem units throughout. A standard type scale: body = 1rem, h3 = 1.25rem, h2 = 1.5rem, h1 = 2rem.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> html { font-size: 100%; } /* keep browser default (usually 16px) */ /* px — fixed, does not scale with user preferences */ .px-example { font-size: 18px; } /* rem — relative to root html (1rem = 16px by default) */ .rem-example { font-size: 1.5rem; } /* 24px */ /* em — relative to PARENT element */ .parent { font-size: 20px; } .child-em { font-size: 1.5em; } /* 30px (1.5 × 20px parent) */ /* Type scale using rem */ .scale-sm { font-size: 0.875rem; } /* 14px */ .scale-base{ font-size: 1rem; } /* 16px */ .scale-lg { font-size: 1.25rem; } /* 20px */ .scale-xl { font-size: 1.5rem; } /* 24px */ .scale-2xl { font-size: 2rem; } /* 32px */ </style> </head> <body> <p class="scale-sm">0.875rem — small text</p> <p class="scale-base">1rem — base body text</p> <p class="scale-lg">1.25rem — large text</p> <p class="scale-xl">1.5rem — extra large</p> <p class="scale-2xl">2rem — heading size</p> </body> </html>

Key Points

  • font-size sets text size. Units: px, rem, em, %.
  • rem = relative to root html (1rem ≈ 16px). Preferred unit.
  • em = relative to parent element font-size (can compound).
  • Never lock html { font-size: 12px } — breaks accessibility.
13

font-weight Property

Q14

The font-weight property sets how thick or thin text appears. Named values: normal (400) and bold (700). Numeric values 100–900 in steps of 100 give finer control when the font provides multiple weights: 300 (light), 400 (normal), 500 (medium), 600 (semibold), 700 (bold), 800 (extrabold), 900 (black).

The numeric weight only works if the loaded font actually includes that weight. Google Fonts requires you to specify which weights to load in the URL: family=Inter:wght@400;500;600;700. Requesting a weight the font does not have causes the browser to synthesise it by stretching or thickening the nearest available weight, which looks worse than the real weight.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <link href="https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600;700;800;900&display=swap" rel="stylesheet"> <style> body { font-family: 'Inter', sans-serif; font-size: 1.1rem; } /* Named values */ .normal { font-weight: normal; } /* = 400 */ .bold { font-weight: bold; } /* = 700 */ /* Numeric values */ .w300 { font-weight: 300; } /* Light */ .w400 { font-weight: 400; } /* Regular */ .w500 { font-weight: 500; } /* Medium */ .w600 { font-weight: 600; } /* SemiBold */ .w700 { font-weight: 700; } /* Bold */ .w900 { font-weight: 900; } /* Black */ </style> </head> <body> <p class="w300">300 — Light</p> <p class="w400">400 — Regular (normal)</p> <p class="w500">500 — Medium</p> <p class="w600">600 — SemiBold</p> <p class="w700">700 — Bold</p> <p class="w900">900 — Black</p> </body> </html>

Key Points

  • font-weight: normal (400) or bold (700) — or numeric 100–900.
  • 100 = Thin, 300 = Light, 400 = Regular, 700 = Bold, 900 = Black.
  • Numeric weights only work if the font includes that weight.
  • Google Fonts: request weights in URL — family=Inter:wght@400;700.
14

font-style Property

Q15

The font-style property controls whether text is displayed in italic or oblique (slanted) style. Values: normal (default upright), italic (the font's true italic variant, redrawn at a slight angle with different letterforms), and oblique (the browser slants the normal font artificially).

Use the CSS font-style: italic in preference to the HTML <i> element when the italic is purely visual with no semantic meaning. Reserve the HTML <em> element (which also renders italic by default) for text with actual semantic emphasis that changes the meaning of a sentence.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .normal { font-style: normal; } .italic { font-style: italic; } .oblique { font-style: oblique; } /* artificial slant */ /* Practical use: labels, captions, quotes */ blockquote { font-style: italic; color: #64748b; border-left: 3px solid #10B981; padding-left: 16px; } .caption { font-style: italic; font-size: 0.875rem; color: #94a3b8; } </style> </head> <body> <p class="normal">Normal — upright text</p> <p class="italic">Italic — true italic letterforms</p> <p class="oblique">Oblique — artificially slanted</p> <br> <blockquote>"CSS is the language of the web's visual layer."</blockquote> <p class="caption">Figure 1: Example of a styled blockquote</p> </body> </html>

Key Points

  • font-style: normal (default) | italic | oblique.
  • italic uses the font's true italic variant (different letterforms).
  • oblique artificially slants the normal font.
  • Use CSS font-style for visual italics; <em> for semantic emphasis.
15

text-align Property

Q16

The text-align property controls the horizontal alignment of text inside its container. Values: left (default for LTR languages), right, center, and justify (stretches text to fill the full width, like a newspaper column).

A common beginner mistake is trying to center a whole element (e.g., a <div>) using text-align: center. This only centers the text inside the element. To center a block element itself, use margin: 0 auto with a defined width, or use Flexbox on the parent.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .left { text-align: left; } /* default */ .center { text-align: center; } .right { text-align: right; } .justify { text-align: justify; } div { border: 1px dashed #cbd5e1; padding: 12px; margin: 8px 0; max-width: 500px; } /* Center the DIV itself (not its text) using margin: auto */ .centered-box { width: 300px; margin: 0 auto; background: #ecfdf5; padding: 20px; text-align: center; } </style> </head> <body> <div class="left">text-align: left — default</div> <div class="center">text-align: center — centered text</div> <div class="right">text-align: right — right-aligned</div> <div class="justify">text-align: justify — The text in this paragraph is stretched to reach both edges of the box, just like a newspaper column layout.</div> <div class="centered-box">This box is centered on the page using margin: 0 auto</div> </body> </html>

Key Points

  • text-align: left | center | right | justify.
  • Centers text INSIDE an element — not the element itself.
  • To center a block element: use margin: 0 auto with a fixed width.
  • justify stretches text to fill the line (newspaper style).
16

Box Model: Padding

Q17

Every HTML element is treated as a rectangular box with four layers. From inside out: content → padding → border → margin. Padding is the space inside the element, between the content and the border. It is part of the element's background and is clickable.

You can set padding on all four sides at once with shorthand: padding: 10px (all four sides equal); padding: 10px 20px (top+bottom 10px, left+right 20px); padding: 5px 10px 15px 20px (top, right, bottom, left — clockwise from top). Individual sides: padding-top, padding-right, padding-bottom, padding-left.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .box { background: #ecfdf5; border: 2px solid #10B981; width: 300px; font-family: sans-serif; } /* Different padding examples */ .p-none { padding: 0; } .p-all { padding: 20px; } .p-tb-lr { padding: 10px 40px; } /* top+bottom / left+right */ .p-sides { padding-left: 32px; padding-right: 32px; } .label { font-size: 11px; color: #059669; margin-bottom: 6px; } div { margin-bottom: 10px; } </style> </head> <body> <div class="box p-none"> <span class="label">padding: 0 — content touches the border</span> Content here </div> <div class="box p-all"> <span class="label">padding: 20px — all four sides</span> Content here </div> <div class="box p-tb-lr"> <span class="label">padding: 10px 40px — top/bottom + left/right</span> Content here </div> </body> </html>

Key Points

  • Padding = space INSIDE the border (between content and border).
  • Padding has the element's background colour — it is clickable.
  • Shorthand: 1 value (all) | 2 values (TB, LR) | 4 values (T R B L).
  • Individual: padding-top, padding-right, padding-bottom, padding-left.
17

Box Model: Margin

Q18

The margin is the outermost layer of the box model — space outside the element's border, separating it from neighbouring elements. Margins are transparent; the page background shows through them. The same shorthand rules apply as for padding: 1, 2, or 4 values.

An important quirk: vertical margins collapse. When two block elements stack vertically, their top and bottom margins merge into one, equal to the larger margin. For example, a paragraph with margin-bottom: 20px above another with margin-top: 30px results in 30px of space between them — not 50px. Horizontal margins do not collapse.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .box { background: #ecfdf5; border: 2px solid #10B981; padding: 12px; width: 280px; } .m-none { margin: 0; } .m-all { margin: 20px; } .m-auto { margin: 0 auto; } /* centres the block */ .m-sides { margin-left: 40px; margin-right: 40px; } /* Collapse demo */ .p1 { margin-bottom: 20px; background: #fef3c7; padding: 8px; } .p2 { margin-top: 30px; background: #dbeafe; padding: 8px; } </style> </head> <body> <div class="box m-none">margin: 0</div> <div class="box m-all">margin: 20px — all sides</div> <div class="box m-auto">margin: 0 auto — centred!</div> <hr> <p class="p1">margin-bottom: 20px (yellow)</p> <p class="p2">margin-top: 30px (blue) — gap = 30px, not 50px (collapsed)</p> </body> </html>

Key Points

  • Margin = space OUTSIDE the border (between elements).
  • Transparent — the page background shows through margin areas.
  • margin: 0 auto centers a block element (needs a fixed width).
  • Vertical margins collapse — the LARGER margin wins, not their sum.
18

Box Model Width Calculation

Q19

By default (box-sizing: content-box), the width property sets only the content area width. Total rendered width = content width + left padding + right padding + left border + right border. For example: width: 200px; padding: 10px; border: 5px → total = 200 + 10×2 + 5×2 = 230px.

This is confusing and error-prone. That is why the CSS reset uses box-sizing: border-box: with this setting, width includes padding and border, so a 200px element stays 200px regardless of padding. Almost every professional project today uses * { box-sizing: border-box; } as a first line.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Default: content-box — width = content only */ .content-box { box-sizing: content-box; /* default */ width: 200px; padding: 10px; border: 5px solid #10B981; background: #ecfdf5; margin-bottom: 16px; } /* total = 200 + 10*2 + 5*2 = 230px */ /* Better: border-box — width includes padding+border */ .border-box { box-sizing: border-box; width: 200px; padding: 10px; border: 5px solid #7c3aed; background: #f5f3ff; } /* total = exactly 200px — content shrinks to 170px */ p { font-size: 13px; color: #475569; margin-top: 4px; } </style> </head> <body> <div class="content-box">content-box</div> <p>→ Actual width = 200 + 10×2 + 5×2 = <strong>230px</strong></p> <div class="border-box">border-box</div> <p>→ Actual width = exactly <strong>200px</strong></p> </body> </html>

Key Points

  • Default (content-box): total width = content + padding×2 + border×2.
  • Example: width:200 + padding:10 + border:5 → 200+20+10 = 230px.
  • box-sizing: border-box makes width include padding and border.
  • Always use * { box-sizing: border-box } at the top of your CSS.
19

display: block

Q20

The display property is one of the most powerful in CSS. display: block makes an element behave as a block-level element: it starts on a new line, takes up the full available width, and respects width/height/margin settings. Block elements stack vertically.

Elements that are block by default: div, p, h1–h6, ul, li, section, article, header, footer. You can change any inline element to block with display: block — for example, making a link fill a whole row: a { display: block; } is common in navigation menus.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* span is inline by default — force it to block */ .forced-block { display: block; background: #ecfdf5; border: 2px solid #10B981; padding: 12px; margin: 6px 0; width: 300px; /* now works — block respects width */ } /* block nav links — each fills its row */ nav a { display: block; padding: 10px 16px; background: #1e293b; color: white; text-decoration: none; margin-bottom: 2px; } nav a:hover { background: #15803d; } </style> </head> <body> <span class="forced-block">I am a span — normally inline, forced to block</span> <span class="forced-block">Each span now starts on a new line</span> <nav> <a href="#">Home</a> <a href="#">About</a> <a href="#">Projects</a> </nav> </body> </html>

Key Points

  • display: block — starts new line, full width, stacks vertically.
  • Default block elements: div, p, h1-h6, ul, li, section, footer.
  • Block elements respect width, height, and all margin settings.
  • Can convert any element to block: a { display: block; }
20

display: none

Q21

display: none completely removes an element from the page layout: it is invisible and takes up no space. It is commonly used with JavaScript to show/hide elements dynamically (toggle menus, modals, alerts). This is different from visibility: hidden, which hides the element but keeps its space.

Do not confuse display: none with opacity: 0. Opacity 0 makes an element transparent but it still occupies its space and responds to clicks. The right tool depends on your intent: use display: none for menus that collapse entirely, visibility: hidden to reserve space while hiding, and opacity: 0 for fade transitions.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .box { padding: 16px; margin: 8px 0; border: 2px solid #10B981; } .hidden-none { display: none; } /* gone — no space */ .hidden-visibility { visibility: hidden; } /* hidden but space kept */ .hidden-opacity { opacity: 0; } /* transparent, space kept */ </style> </head> <body> <div class="box">Box 1 — visible</div> <div class="box hidden-none">Box 2 — display:none (you cannot see this)</div> <div class="box">Box 3 — visible (no gap above from box 2!)</div> <div class="box hidden-visibility">Box 4 — visibility:hidden (space kept)</div> <div class="box">Box 5 — there IS a gap above from box 4</div> <hr> <!-- Toggle with JavaScript --> <button onclick="document.getElementById('msg').style.display = document.getElementById('msg').style.display === 'none' ? 'block' : 'none'"> Toggle Message </button> <div id="msg" class="box" style="display:none">Hello! I was hidden.</div> </body> </html>

Key Points

  • display: none removes element completely — takes up no space.
  • visibility: hidden hides but keeps the space (element still there).
  • opacity: 0 makes transparent — still occupies space and is clickable.
  • JavaScript toggles: element.style.display = 'none' or 'block'.
21

display: flex

Q22

display: flex activates the Flexbox layout model on a container element. Its children (flex items) automatically arrange in a row (horizontal, by default) and can be aligned, spaced, wrapped, and ordered with CSS properties. Flexbox solved layout problems that were extremely difficult in older CSS.

The most useful Flexbox properties on the container: flex-direction (row or column), justify-content (main-axis alignment: space-between, center, etc.), align-items (cross-axis alignment: center, stretch, etc.), and gap (space between items). On the item: flex: 1 makes the item grow to fill remaining space.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Flexbox container */ .flex-row { display: flex; gap: 12px; background: #f8fafc; padding: 16px; border: 1px solid #e2e8f0; border-radius: 8px; margin-bottom: 16px; } .flex-row.center { justify-content: center; } .flex-row.between { justify-content: space-between; } .flex-row.align-c { align-items: center; } .item { background: #10B981; color: white; padding: 12px 20px; border-radius: 6px; font-weight: 600; } .item.tall { height: 60px; display: flex; align-items: center; } .item.grow { flex: 1; } /* grows to fill remaining space */ </style> </head> <body> <div class="flex-row"> <div class="item">A</div> <div class="item">B</div> <div class="item">C</div> </div> <div class="flex-row between"> <div class="item">Left</div> <div class="item">Right</div> </div> <div class="flex-row"> <div class="item tall">Tall</div> <div class="item grow">flex:1 — fills remaining width</div> </div> </body> </html>

Key Points

  • display: flex turns a container into a Flexbox — children line up in a row.
  • justify-content controls main-axis (horizontal): center, space-between.
  • align-items controls cross-axis (vertical): center, stretch, flex-start.
  • gap sets space between items; flex:1 on an item fills remaining space.
22

CSS Specificity

Q23

Specificity is a score the browser calculates for each CSS selector to decide which rule wins when two or more rules target the same element with the same property. Specificity is written as three numbers: (ID, Class, Type). A higher number in the leftmost column always wins, regardless of the numbers in other columns.

Specificity scores: !important (override all — avoid), inline style (1,0,0,0), ID selector (0,1,0,0), class/attribute/pseudo-class (0,0,1,0), type selector/pseudo-element (0,0,0,1), universal selector (0,0,0,0). The order in the stylesheet breaks ties of equal specificity — the later rule wins.

HTML / CSS
/* Specificity examples — higher number wins */ p { color: gray; } /* (0,0,0,1) type = 1 */ .intro { color: blue; } /* (0,0,1,0) class = 10 */ #main { color: green; } /* (0,1,0,0) ID = 100 */ p.intro { color: purple; } /* (0,0,1,1) = 11 */ #main p { color: orange; } /* (0,1,0,1) = 101 */ /* Example: which colour does this element get? <p class="intro" id="main"> ... </p> Rules that match: p (1), .intro (10), p.intro (11), #main (100), #main p (101) Winner: #main p with score 101 → orange */ /* Bad practice — avoid! */ p { color: red !important; } /* overrides EVERYTHING — hard to debug */

Key Points

  • Specificity score: (ID, Class, Type) — leftmost column always wins.
  • ID=100, class=10, type=1 (metaphorically — they don't carry over).
  • Equal specificity? The LATER rule in the stylesheet wins.
  • Avoid !important — it breaks the cascade and is hard to debug.
23

Which Selector Wins?

Q24

Combining selectors increases specificity. The selector #hero .title scores (1,1,0) — 1 ID + 1 class — and beats both #hero alone (1,0,0) would not beat an inline style, but beats any class-only selector. Understanding which rule wins is essential for debugging CSS.

Practical tip: keep specificity low. Use class selectors for most styling. Avoid ID selectors in CSS (use them for JS). Never rely on ordering to resolve conflicts. If you find yourself fighting the cascade with !important, it usually means your selector structure needs refactoring.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Which wins? Match the selector and count the score */ p { color: gray; } /* score: 0,0,0,1 — type */ .highlight { color: blue; } /* score: 0,0,1,0 — class */ p.highlight { color: purple; } /* score: 0,0,1,1 — type+class */ #note { color: green; } /* score: 0,1,0,0 — ID */ /* Combinators add up */ div p { font-style: italic; } /* 0,0,0,2 */ div .highlight { font-weight: bold; } /* 0,0,1,1 */ </style> </head> <body> <!-- gray: matched by p (0,0,0,1) only --> <p>Plain paragraph — gray</p> <!-- purple: p.highlight (0,0,1,1) beats p (0,0,0,1) and .highlight (0,0,1,0) --> <p class="highlight">P with class — purple (p.highlight wins)</p> <!-- green: #note (0,1,0,0) beats everything above --> <p class="highlight" id="note">P with class AND id — green (#note wins)</p> </body> </html>

Key Points

  • Higher ID count always beats class count; class always beats type.
  • Inline style beats any stylesheet rule (unless !important).
  • Same specificity? Later rule in the file wins.
  • Best practice: keep specificity low — class selectors for styling.
24

CSS Comments

Q25

CSS comments are written between /* and */. Everything between these markers is ignored by the browser. Comments are useful for: explaining complex selectors, marking sections of a large stylesheet, temporarily disabling a rule for debugging, and leaving notes for teammates.

Unlike HTML comments (<!-- -->), CSS comments can span multiple lines. There is no single-line comment syntax in CSS (// does not work in standard CSS). Inside a <style> block in HTML, use CSS comment syntax — not HTML comment syntax.

HTML / CSS
/* ───────────────────────────────────────────── TYPOGRAPHY STYLES Used on all pages — last updated 2026-09-14 ───────────────────────────────────────────── */ body { font-family: 'Inter', sans-serif; font-size: 1rem; line-height: 1.7; /* color: red; */ /* temporarily disabled — was too harsh */ color: #1e293b; } /* Navigation */ nav { display: flex; gap: 16px; } /* horizontal layout */ /* TODO: add mobile breakpoint here */ /* @media (max-width: 768px) { ... } */ /* These do NOT work in CSS: */ /* // This is NOT a CSS comment — JavaScript only */ <!-- This is NOT a CSS comment — HTML only -->

Key Points

  • CSS comment syntax: /* comment text */ — can span multiple lines.
  • // and do NOT work as CSS comments.
  • Use comments to mark sections, explain WHY, and disable code for debugging.
  • Comments are stripped before the file is sent to the browser.
