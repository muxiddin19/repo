01

position: static & relative

Q1 Q2

The CSS position property has five values. The default is static — the element sits in the normal document flow and the offset properties (top, right, bottom, left) have no effect. Every element is static unless you say otherwise.

position: relative keeps the element in the normal flow (other elements still see it where it was) but lets you shift it visually using the offset properties. The shift is relative to where the element would normally be. This value is also the most common way to create a positioned ancestor for absolutely positioned children.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .box { width: 120px; height: 60px; background: #0f766e; color: white; padding: 8px; margin: 6px; font-size: 14px; } /* static: default — offsets ignored */ .static { position: static; } /* relative: offsets work — moves FROM its natural position */ .relative { position: relative; top: 20px; /* moves DOWN 20px from natural spot */ left: 30px; /* moves RIGHT 30px */ background: #14b8a6; } </style> </head> <body> <div class="box static">static (default)</div> <div class="box relative">relative — shifted ↓20px →30px</div> <div class="box static">Next element — unaffected by relative shift above</div> </body> </html>

Key Points

  • position: static = default; top/left/right/bottom have NO effect.
  • position: relative shifts visually but keeps its place in the flow.
  • Surrounding elements are NOT affected by a relative shift.
  • relative is also used to create a positioned ancestor for absolute children.
02

position: absolute

Q3

position: absolute removes the element entirely from the normal flow — other elements close the gap as if it never existed. It is then positioned using top, right, bottom, left relative to its nearest positioned ancestor (any parent with position not equal to static).

If no positioned ancestor exists, the element anchors to the <body> (or the initial containing block). The most common pattern: set position: relative on the parent and position: absolute on the child to create a tooltip, badge, or overlay precisely placed within that parent.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .card { position: relative; /* creates the anchor for absolute children */ width: 280px; height: 160px; background: #f0fdfa; border: 2px solid #14b8a6; border-radius: 10px; margin: 40px; } /* Badge anchored to top-right corner of .card */ .badge { position: absolute; top: -12px; right: -12px; background: #0f766e; color: white; font-size: 12px; font-weight: bold; padding: 4px 10px; border-radius: 20px; } .card-title { padding: 20px; font-size: 18px; font-weight: bold; color: #0f766e; } </style> </head> <body> <div class="card"> <span class="badge">NEW</span> <div class="card-title">CSS Advanced Guide</div> </div> </body> </html>

Key Points

  • position: absolute removes element from the flow — no space left behind.
  • Positioned relative to nearest ancestor with position ≠ static.
  • Pattern: parent gets position:relative, child gets position:absolute.
  • top:-12px places the badge 12px ABOVE the parent's top edge.
03

position: fixed & sticky

Q4 Q5

position: fixed removes the element from the flow and positions it relative to the viewport (the browser window). It stays exactly in place when you scroll — perfect for sticky navigation bars, floating action buttons, and cookie consent banners.

position: sticky is a hybrid: it behaves like relative until you scroll to a defined threshold (e.g. top: 0), then it 'sticks' in place like fixed — but only within its parent container. When you scroll past the parent, the sticky element scrolls away too. Used for table headers and section labels.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> body { margin: 0; font-family: sans-serif; } /* Fixed nav — always visible, sits outside the flow */ .fixed-nav { position: fixed; top: 0; left: 0; right: 0; background: #0f766e; color: white; padding: 14px 24px; z-index: 100; /* above everything else */ } .content { padding-top: 60px; } /* offset for fixed nav height */ /* Sticky section title */ .sticky-header { position: sticky; top: 56px; /* sticks 56px from top (below fixed nav) */ background: #ccfbf1; border-left: 4px solid #14b8a6; padding: 10px 16px; font-weight: bold; color: #0f766e; } .section-body { padding: 20px; height: 300px; /* tall enough to scroll */ background: #f0fdfa; } </style> </head> <body> <nav class="fixed-nav">Fixed Navigation — always visible while scrolling</nav> <div class="content"> <div> <div class="sticky-header">Section A — sticky header</div> <div class="section-body">Scroll down to see the sticky header in action…</div> </div> <div> <div class="sticky-header">Section B — another sticky header</div> <div class="section-body">Each section has its own sticky label.</div> </div> </div> </body> </html>

Key Points

  • position: fixed → viewport anchor, never moves when scrolling.
  • position: sticky → hybrid: relative → fixed at scroll threshold.
  • sticky only works within its parent container.
  • Always add z-index to fixed elements so they stay on top.
04

z-index & overflow

Q6 Q7

z-index controls the stacking order of positioned elements (elements with position not equal to static). A higher z-index appears on top. The default z-index is auto (effectively 0). Negative values push an element behind the normal flow.

overflow controls what happens when an element's content is larger than its box. overflow: hidden clips the excess. overflow: scroll always shows scrollbars. overflow: auto shows scrollbars only when needed. overflow: visible (default) lets content spill outside.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .stack { position: relative; height: 200px; } .layer { position: absolute; width: 180px; height: 100px; padding: 10px; border-radius: 8px; font-size: 14px; } .layer-1 { background:#0f766e; color:white; top:20px; left:20px; z-index:1; } .layer-2 { background:#14b8a6; color:white; top:50px; left:80px; z-index:2; } .layer-3 { background:#ccfbf1; color:#0f766e; top:80px;left:140px; z-index:3; } /* overflow demo */ .overflow-demo { width: 220px; height: 90px; overflow: hidden; /* try: scroll | auto | visible */ border: 2px solid #14b8a6; padding: 8px; margin-top: 16px; font-size: 14px; line-height: 1.6; } </style> </head> <body> <div class="stack"> <div class="layer layer-1">z-index: 1 (bottom)</div> <div class="layer layer-2">z-index: 2 (middle)</div> <div class="layer layer-3">z-index: 3 (top)</div> </div> <div class="overflow-demo"> overflow: hidden clips everything outside the box. This text is too long to fit and will be cut off. You will not see this last sentence at all. </div> </body> </html>

Key Points

  • z-index only works on positioned elements (position ≠ static).
  • Higher z-index = closer to the viewer (on top).
  • overflow: hidden clips excess; auto adds scrollbars only when needed.
  • Combining position:relative + overflow:hidden is a classic mask trick.
05

Pseudo-classes

Q8 Q9 Q10

A pseudo-class is a selector that targets an element in a particular state. The state is dynamic — it changes as the user interacts. The most used: :hover (mouse over), :focus (keyboard/click focus), :active (being clicked), :visited (link already opened), :first-child, :last-child, and :nth-child(n).

:focus is critical for accessibility. Never remove it entirely with outline: none without providing a visible alternative. Users who navigate with a keyboard rely on the focus ring to know which element is active. :focus-visible is a modern pseudo-class that shows focus only when using keyboard navigation, hiding it for mouse clicks — best of both worlds.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* :hover — mouse over */ .btn { background: #0f766e; color: white; border: none; padding: 10px 20px; border-radius: 6px; cursor: pointer; transition: background 0.2s, transform 0.15s; } .btn:hover { background: #14b8a6; transform: translateY(-2px); } .btn:active { transform: scale(0.97); } /* :focus-visible — keyboard focus only */ input { border: 2px solid #94a3b8; border-radius: 6px; padding: 8px 12px; font-size: 15px; outline: none; transition: border-color 0.2s; } input:focus-visible { border-color: #0f766e; box-shadow: 0 0 0 3px #99f6e4; } /* :nth-child — stripe table rows */ table { border-collapse: collapse; width: 260px; margin-top: 16px; font-size: 14px; } td { padding: 6px 12px; } tr:nth-child(even) { background: #f0fdfa; } tr:nth-child(odd) { background: white; } tr:first-child { background: #0f766e; color: white; font-weight: bold; } </style> </head> <body> <button class="btn">Hover & Click Me</button><br><br> <input type="text" placeholder="Tab here to see :focus-visible"><br> <table> <tr><td>Name</td><td>Score</td></tr> <tr><td>Alice</td><td>98</td></tr> <tr><td>Bob</td><td>85</td></tr> <tr><td>Carol</td><td>91</td></tr> <tr><td>Dave</td><td>77</td></tr> </table> </body> </html>

Key Points

  • :hover fires when mouse is over — use for UI feedback.
  • :focus when element receives focus — NEVER hide without an alternative.
  • :focus-visible is better: shows focus only for keyboard, not mouse.
  • :nth-child(2n) = even rows; :nth-child(2n+1) = odd rows.
06

Pseudo-elements ::before & ::after

Q11 Q12

A pseudo-element creates a virtual sub-element that can be styled independently. ::before inserts it immediately before the element's content; ::after inserts it immediately after. Both are generated by CSS alone — no extra HTML needed.

The content property is mandatory — without it the pseudo-element does not render (even content: '' with an empty string is required for purely decorative uses). Once it exists, you can give it any CSS properties: display, position, background, width, height, etc.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* ::before adds a decorative leaf icon */ h2::before { content: '🌿 '; } /* ::after adds a required asterisk to labels */ .required::after { content: ' *'; color: #f43f5e; font-weight: bold; } /* ::before as a decorative underline bar */ .underline-title { position: relative; display: inline-block; padding-bottom: 8px; } .underline-title::after { content: ''; position: absolute; bottom: 0; left: 0; width: 100%; height: 3px; background: #0f766e; border-radius: 2px; } /* ::before as a quotation mark */ blockquote { position: relative; padding-left: 36px; font-style: italic; } blockquote::before { content: '"'; position: absolute; left: 0; top: -8px; font-size: 56px; color: #14b8a6; line-height: 1; } </style> </head> <body> <h2>CSS Pseudo-elements</h2> <p><label class="required">Email address</label></p> <p class="underline-title">Decorative Underline</p> <blockquote>CSS gives you superpowers — no JavaScript needed.</blockquote> </body> </html>

Key Points

  • ::before inserts before the content; ::after inserts after.
  • content: property is REQUIRED — even content:'' for decorative only.
  • Pseudo-elements can be positioned (absolute/relative) and sized.
  • No extra HTML: one CSS rule, applied to every matching element.
07

CSS Transitions

Q13

The transition property smoothly animates a CSS property change over time. The shorthand takes four values: property duration timing-function delay. For example: transition: background 0.3s ease — when background changes (e.g., on :hover), the browser interpolates between old and new over 300ms with an ease curve.

Always put transition on the base state, not the :hover state — this ensures the animation plays both ways (forward on hover, reverse when leaving). You can animate multiple properties by separating with commas: transition: background 0.3s, transform 0.2s. Avoid transition: all — it is slow and can animate properties you don't intend.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> .card { width: 240px; padding: 24px; background: #f0fdfa; border: 2px solid #14b8a6; border-radius: 12px; color: #0f766e; font-size: 16px; margin: 20px; /* transition on BASE state — animates BOTH forward and reverse */ transition: background 0.3s ease, transform 0.2s ease, box-shadow 0.3s ease; } .card:hover { background: #0f766e; color: white; transform: translateY(-6px); box-shadow: 0 12px 32px rgba(0,0,0,0.2); } /* Opacity transition — fade out */ .fade-btn { opacity: 1; transition: opacity 0.4s ease; padding: 10px 20px; background: #14b8a6; color: white; border: none; border-radius: 6px; cursor: pointer; } .fade-btn:hover { opacity: 0.5; } </style> </head> <body> <div class="card">Hover over this card</div> <button class="fade-btn">Hover to fade</button> </body> </html>

Key Points

  • transition: property duration timing delay — all four in order.
  • Put transition on the BASE element, not the :hover rule.
  • Comma-separate multiple transitions: background 0.3s, transform 0.2s.
  • Avoid transition:all — name specific properties for performance.
08

CSS Animations & @keyframes

Q14

@keyframes defines a multi-step animation sequence: you name it, then describe the CSS properties at each percentage point from 0% (start) to 100% (end). You can add as many stops as needed. The animation property then attaches the sequence to an element.

The animation shorthand: name duration timing-function delay iteration-count direction fill-mode. The most important non-obvious value is fill-mode: forwards — without it the element snaps back to its initial state when the animation finishes. Use iteration-count: infinite for looping animations like loading spinners.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Fade + slide in */ @keyframes fadeSlideIn { from { opacity: 0; transform: translateY(30px); } to { opacity: 1; transform: translateY(0); } } /* Pulse */ @keyframes pulse { 0%, 100% { transform: scale(1); opacity: 1; } 50% { transform: scale(1.1); opacity: 0.7; } } /* Spinning loader */ @keyframes spin { from { transform: rotate(0deg); } to { transform: rotate(360deg); } } .hero { animation: fadeSlideIn 0.8s ease-out forwards; font-size: 28px; font-weight: bold; color: #0f766e; padding: 20px; } .badge { display: inline-block; background: #0f766e; color: white; padding: 6px 16px; border-radius: 20px; animation: pulse 1.5s ease-in-out infinite; } .spinner { width: 40px; height: 40px; border: 4px solid #ccfbf1; border-top-color: #0f766e; border-radius: 50%; animation: spin 0.8s linear infinite; margin: 20px; } </style> </head> <body> <div class="hero">Hello! I faded and slid in on load.</div> <span class="badge">Live</span> <div class="spinner"></div> </body> </html>

Key Points

  • @keyframes name { from{} to{} } or 0%{} 25%{} 100%{}.
  • animation: name duration timing delay iterations direction fill-mode.
  • fill-mode: forwards keeps the final state — without it element snaps back.
  • iteration-count: infinite loops forever — perfect for spinners.

CSS Custom Properties (Variables)

Q15 Q16

CSS custom properties — declared with a -- prefix and read back with var() — are the closest CSS gets to variables in a programming language. Declare them on :root to make them globally available. They cascade and can be overridden on any element.

The main superpower: change one variable and every use of it updates instantly. This makes design tokens (colour palette, spacing scale, border radius) easy to maintain. Dark mode becomes a matter of redefining a handful of variables inside a @media (prefers-color-scheme: dark) block — no JavaScript required.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Global design tokens */ :root { --color-primary: #0f766e; --color-accent: #14b8a6; --color-bg: #f0fdfa; --color-text: #1e293b; --radius-card: 12px; --shadow-card: 0 4px 20px rgba(0,0,0,0.1); --spacing-md: 20px; } /* Automatic dark mode — just redefine the tokens */ @media (prefers-color-scheme: dark) { :root { --color-bg: #051a0a; --color-text: #d4edda; } } body { background: var(--color-bg); color: var(--color-text); font-family: sans-serif; } .btn { background: var(--color-primary); color: white; padding: 10px 24px; border: none; border-radius: var(--radius-card); cursor: pointer; } .btn:hover { background: var(--color-accent); } .card { background: var(--color-bg); border: 2px solid var(--color-accent); border-radius: var(--radius-card); padding: var(--spacing-md); box-shadow: var(--shadow-card); margin-top: var(--spacing-md); max-width: 300px; color: var(--color-text); } /* Local override — this card uses red as primary */ .card.danger { --color-primary: #f43f5e; --color-accent: #fb7185; } </style> </head> <body> <button class="btn">Primary Button</button> <div class="card"> <strong>Default Card</strong><br>Uses global --color-primary (teal) </div> <div class="card danger"> <strong>Danger Card</strong><br>Local override: --color-primary = red </div> </body> </html>

Key Points

  • Declare: --name: value; (on :root for global scope).
  • Use: color: var(--name); — anywhere in CSS.
  • They cascade — override on any element for local theming.
  • Dark mode: redefine variables inside @media (prefers-color-scheme: dark).

CSS Media Queries

Q17

Media queries apply CSS conditionally. The most common condition is max-width or min-width for responsive layouts. The recommended approach is mobile-first: write base styles for the smallest screen, then use min-width breakpoints to progressively enhance for wider screens.

Beyond width, media queries support: orientation (landscape/portrait), prefers-color-scheme (dark/light), prefers-reduced-motion (disable animations for accessibility), and the print media type for print stylesheets.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <style> /* BASE STYLES — mobile-first (< 768px) */ body { font-family: sans-serif; padding: 16px; background: #f0fdfa; } .grid { display: flex; flex-direction: column; gap: 16px; } .card { background: white; border: 2px solid #14b8a6; border-radius: 10px; padding: 20px; font-size: 16px; color: #0f766e; } .breakpoint-label { font-size: 14px; background: #0f766e; color: white; padding: 6px 12px; border-radius: 4px; margin-bottom: 12px; display: inline-block; } /* TABLET ≥ 640px — 2 column grid */ @media (min-width: 640px) { .grid { flex-direction: row; flex-wrap: wrap; } .card { flex: 1; min-width: 200px; } } /* DARK MODE */ @media (prefers-color-scheme: dark) { body { background: #051a0a; } .card { background: #0b2017; border-color: #14b8a6; color: #d4edda; } } /* PRINT — hide decorative elements */ @media print { .breakpoint-label { display: none; } body { background: white; } } </style> </head> <body> <div class="breakpoint-label">Resize the preview to see the grid change</div> <div class="grid"> <div class="card">Card One</div> <div class="card">Card Two</div> <div class="card">Card Three</div> </div> </body> </html>

Key Points

  • @media (min-width: 640px) {} — mobile-first, add complexity upward.
  • max-width targets screens UP TO that size; min-width targets ABOVE.
  • prefers-color-scheme: dark enables automatic dark mode CSS.
  • prefers-reduced-motion: reduce disables animations for accessibility.

Advanced Flexbox

Q18 Q19

You already know display: flex, justify-content, and align-items. Now the deeper properties: flex-direction changes the main axis from row (default, horizontal) to column (vertical). flex-wrap: wrap allows items to break onto new lines when they overflow — essential for responsive card grids.

flex: 1 (shorthand for flex-grow: 1; flex-shrink: 1; flex-basis: 0) tells an item to grow and fill available space. order visually reorders items without changing the HTML source order (useful for responsive reordering). align-self overrides align-items for a single item.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* flex-wrap: wrap — cards flow to new rows when narrow */ .card-grid { display: flex; flex-wrap: wrap; /* items wrap to next row */ gap: 16px; padding: 16px; background: #f0fdfa; } .card { flex: 1; /* grow to fill available space */ min-width: 160px; /* but never smaller than 160px */ background: #0f766e; color: white; padding: 20px; border-radius: 10px; text-align: center; } .card.featured { order: -1; /* move to front without changing HTML */ flex: 2; /* twice as wide */ background: #14b8a6; } /* flex-direction: column layout */ .sidebar-layout { display: flex; gap: 16px; margin-top: 16px; } .sidebar { width: 180px; flex-shrink: 0; background: #ccfbf1; padding: 16px; border-radius: 10px; font-size: 14px; } .main { flex: 1; background: white; border: 2px solid #14b8a6; padding: 16px; border-radius: 10px; } </style> </head> <body> <div class="card-grid"> <div class="card">A</div> <div class="card">B</div> <div class="card featured">FEATURED — order:-1, flex:2</div> <div class="card">C</div> <div class="card">D</div> </div> <div class="sidebar-layout"> <aside class="sidebar">Sidebar (fixed 180px)</aside> <main class="main">Main content (flex:1 — fills remaining space)</main> </div> </body> </html>

Key Points

  • flex-wrap: wrap allows items to flow to new lines — essential for responsive grids.
  • flex: 1 = grow to fill space; flex: 2 = take twice as much space.
  • min-width on flex items prevents them shrinking too small.
  • order: -1 moves an item to the front visually without changing HTML.

CSS Grid

Q20 Q21 Q22

CSS Grid is a two-dimensional layout system — you define both rows and columns simultaneously. display: grid on a container turns its children into grid items. grid-template-columns defines the column structure; grid-template-rows defines rows. The fr unit means 'fraction of the remaining space'.

Items can span multiple cells with grid-column: 1 / 3 (from column line 1 to 3) or grid-column: span 2 (shorthand). Named template areas (grid-template-areas) are the most readable approach: draw the layout in text form, assign children with grid-area. Use Grid for the overall page structure and Flexbox for one-dimensional components.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> /* Named areas layout */ .page { display: grid; grid-template-areas: "header header header" "sidebar main main" "footer footer footer"; grid-template-columns: 200px 1fr 1fr; grid-template-rows: auto 1fr auto; gap: 12px; min-height: 340px; padding: 12px; background: #f0fdfa; } .page > * { border-radius: 8px; padding: 16px; font-size: 14px; font-weight: bold; } header { grid-area: header; background: #0f766e; color: white; } .sidebar{ grid-area: sidebar; background: #ccfbf1; color: #0f766e; } main { grid-area: main; background: white; border: 2px solid #14b8a6; color: #0f766e; } footer { grid-area: footer; background: #1e293b; color: #94a3b8; } /* Simple 3-column card grid */ .cards { display: grid; grid-template-columns: repeat(3, 1fr); gap: 12px; margin-top: 12px; } .cards div { background: #0f766e; color: white; padding: 12px; border-radius: 6px; text-align: center; font-size: 13px; } </style> </head> <body> <div class="page"> <header>Header (spans all 3 columns)</header> <div class="sidebar">Sidebar<br>(200px fixed)</div> <main>Main content (flex: fills remaining 2 columns)</main> <footer>Footer (spans all 3 columns)</footer> </div> <div class="cards"> <div>Card 1</div><div>Card 2</div><div>Card 3</div> <div>Card 4</div><div>Card 5</div><div>Card 6</div> </div> </body> </html>

Key Points

  • display: grid activates the Grid layout on a container.
  • grid-template-columns: repeat(3, 1fr) → 3 equal-width columns.
  • gap sets space between ALL grid cells (rows and columns).
  • Named template areas make the page structure readable as code.
13

border-radius & box-shadow

Q23 Q24

border-radius rounds the corners of an element's border box. A value of 8px gives a subtle rounded card look; 50% on a square element creates a perfect circle. You can set each corner independently: border-radius: 8px 24px 8px 24px (top-left, top-right, bottom-right, bottom-left clockwise).

box-shadow adds a shadow behind an element: box-shadow: h-offset v-offset blur spread color. The blur radius (3rd value) controls softness. spread (4th, optional) expands or contracts the shadow. Use inset before the values for an inner shadow. Multiple shadows are comma-separated.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> body { background: #f0fdfa; padding: 30px; font-family: sans-serif; } .row { display: flex; gap: 20px; margin-bottom: 20px; flex-wrap: wrap; } /* border-radius variety */ .r-none { border-radius: 0; } .r-sm { border-radius: 6px; } .r-lg { border-radius: 20px; } .r-pill { border-radius: 100px;} .r-circle{ border-radius: 50%; width: 80px; height: 80px; line-height: 80px; text-align: center; } /* box-shadow variety */ .s-sm { box-shadow: 0 2px 8px rgba(0,0,0,0.1); } .s-md { box-shadow: 0 4px 16px rgba(0,0,0,0.15); } .s-lg { box-shadow: 0 8px 32px rgba(0,0,0,0.2); } .s-col { box-shadow: 0 4px 20px rgba(15,118,110,0.4); } /* coloured shadow */ .s-in { box-shadow: inset 0 2px 8px rgba(0,0,0,0.2); background: #ccfbf1; } .box { background: #0f766e; color: white; padding: 12px 20px; font-size: 14px; font-weight: bold; } .circle-box { background: #14b8a6; color: white; font-size: 14px; font-weight: bold; } </style> </head> <body> <div class="row"> <div class="box r-none">radius: 0</div> <div class="box r-sm">6px</div> <div class="box r-lg">20px</div> <div class="box r-pill">pill</div> <div class="box r-circle circle-box">50%</div> </div> <div class="row"> <div class="box r-sm s-sm">shadow sm</div> <div class="box r-sm s-md">shadow md</div> <div class="box r-sm s-lg">shadow lg</div> <div class="box r-sm s-col">colored shadow</div> <div class="box r-sm s-in">inset shadow</div> </div> </body> </html>

Key Points

  • border-radius: 8px rounds all 4 corners equally.
  • border-radius: 50% on a square = perfect circle.
  • box-shadow: h v blur spread color — blur is the 3rd value.
  • inset keyword before values creates an inner shadow.

The CSS inherit Keyword

Q25

inherit forces a property to take the same computed value as its parent element. Some CSS properties (like color and font-family) inherit automatically. Others (like border, padding, background) do not inherit — you must explicitly write inherit to force inheritance.

Related keywords: initial resets to the browser's default value for that property. unset is inherit for inherited properties and initial for non-inherited ones — a convenient reset. revert reverts to the browser's default user-agent stylesheet.

HTML / CSS
<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <style> body { color: #0f766e; font-family: 'Georgia', serif; font-size: 18px; } /* inherit: force child to use parent's colour */ .parent { color: #f43f5e; /* red */ font-size: 20px; } .child-inherit { color: inherit; } /* also red — takes from .parent */ .child-normal { } /* also red — color IS inherited */ .child-initial { color: initial; } /* browser default: black */ /* border does NOT inherit */ .with-border { border: 3px solid currentColor; padding: 8px; } /* inherit border from parent */ .parent-bordered { border: 3px solid #0f766e; padding: 12px; } .inherit-border { border: inherit; } /* takes parent's border */ p { margin: 8px 0; } </style> </head> <body> <div class="parent"> <p>Parent — color: red</p> <p class="child-inherit">child color: inherit → red</p> <p class="child-normal">child with no color set → also red (inherits)</p> <p class="child-initial">child color: initial → black (browser default)</p> </div> <hr> <div class="parent-bordered"> Parent has a border <div class="inherit-border" style="margin-top:8px">border: inherit → same border</div> </div> </body> </html>

Key Points

  • inherit forces a property to copy the parent's computed value.
  • color and font-family inherit automatically — most others don't.
  • initial resets to browser default; unset = inherit for inherited props.
  • currentColor is a special value = the element's own color property.
