How to check contrast in Chrome DevTools

The DevTools color picker shows you the ratio

You do not need an external tool. Chrome DevTools has a built-in contrast checker:

  • Open DevTools (F12) and click the Elements panel
  • Click on a text element in the page — e.g., a movie year label
  • In the Styles panel on the right, find the color: property
  • Click the small color swatch next to the hex value
  • The color picker opens. Scroll to the bottom — it shows Contrast ratio: X.XX with a ✔ (AA) or ✘ indicator
  • Drag the color sliders or type a new hex value; the ratio updates live

WCAG AA minimum ratios

  • Normal text (under 18pt / 14pt bold) — requires 4.5:1
  • Large text (18pt+ / 14pt+ bold) — requires 3:1
  • UI components and focus indicators — requires 3:1
Quick tool tip: If you prefer an online checker, try webaim.org/resources/contrastchecker. Enter the foreground and background hex codes and it tells you the ratio and which WCAG levels pass. You can also install the "axe DevTools" browser extension for a one-click audit of the whole page.
