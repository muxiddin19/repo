The two rules of alt text

Rule 1 — Content images need a description that replaces the image

Ask yourself: if the image was replaced by this text, would the user lose information? A movie poster is a content image — it identifies which movie the card is about. A good alt for a poster is "Movie poster for Echoes of Tomorrow (2024)". Bad examples:

  • alt="" on a content image — user gets nothing (screen reader skips silently)
  • alt="image" or alt="img" — just says "image" with no content
  • alt="picsum photos movie4" — leaks implementation details, not useful
  • Missing alt entirely — browser announces the filename (often a UUID or URL)

Rule 2 — Decorative images need alt="" (empty, not missing)

The featured section's editorial photo is purely aesthetic — it duplicates the visual style but carries no unique information. Use alt="" to tell the screen reader to skip it. You can also add role="presentation" for extra safety.

Never omit alt entirely on a decorative image — a missing alt causes the browser to fall back to announcing the filename, which interrupts the reading flow.

Writing good alt text — practical rules: Keep it under 100 characters. Don't start with "Image of" or "Photo of" — screen readers already say "image". Describe the content and function, not the visual style. For a chart or graph, describe the key finding. For a logo, write the company name. For a button image (an icon), write what the button does, not what the icon looks like.
