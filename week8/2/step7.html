JavaScript Loading — Stop Blocking the Page

Two <script> tags in <head> pause HTML parsing. Move them to end of body and add defer for the biggest performance win of the lab.

1 2 3 4 5 6 7

What you are fixing

In broken.html, jQuery and Bootstrap JS are loaded in <head> with no defer or async. Every time the browser's HTML parser reaches a <script>, it stops, downloads the file, executes it, and only then continues building the page. On a slow connection, the user stares at a blank white screen while 150 KB of JS loads. Moving scripts to end-of-body and adding defer lets the HTML render first.

defer vs. async vs. neither — comparison
Loading strategyDownloadsWhen it executesOrder guaranteed?
<script src> in head Blocks HTML parse Immediately (blocks) Yes
<script src> end of body After HTML parsed After HTML ready Yes
<script async> In parallel As soon as downloaded (may interrupt render) No
<script defer> In parallel After HTML fully parsed Yes
<script type="module"> In parallel After HTML parsed (defer by default) Yes
