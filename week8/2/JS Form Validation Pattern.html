The 4-Step Validation Pattern

Every field follows the same structure: shared helpers → per-field validator → real-time listener → submit gate.

Step 1
markValid / markInvalid
Reusable helpers that update aria-invalid and the error span.
Step 2
validateX()
One function per field — calls the helpers and returns true/false.
Step 3
input listener
Runs validateX() on every keystroke for real-time feedback.
Step 4
submit listener
Final gate: calls all validators, blocks submit if any fail.

Pattern Code 
STEP 1 — Helpers
function markValid(input, span) {
  input.setAttribute('aria-invalid', 'false');
  span.textContent = '';
}
function markInvalid(input, span, msg) {
  input.setAttribute('aria-invalid', 'true');
  span.textContent = msg;
}
STEP 2 — Per-field validator
function validateEmail() {
  const el  = document.getElementById('v-email');
  const err = document.getElementById('err-email');
  if (el.validity.valueMissing)
    return markInvalid(el, err, 'Required'), false;
  if (el.validity.typeMismatch)
    return markInvalid(el, err, 'Invalid email'), false;
  return markValid(el, err), true;
}
STEP 3 — Real-time listener
document.getElementById('v-email')
  .addEventListener('input', () => {
    validateEmail();
    submitBtn.disabled = !form.checkValidity();
  });
STEP 4 — Submit gate
form.addEventListener('submit', e => {
  e.preventDefault();
  if (validateSid()
    && validateEmail()
    && validatePw()) {
      showSuccess();
  }
});

Pattern at a Glance

markValid(input, span)

aria-invalid="false", clears error text

markInvalid(input, span, msg)

aria-invalid="true", sets error message

validateX()

Checks one field, calls helpers, returns true/false

form.checkValidity()

Returns true only when all fields pass constraints
