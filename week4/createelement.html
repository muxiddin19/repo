createElement & appendChild

JavaScript can build new elements and put them on the page: create, configure, append.

JavaScript
const li = document.createElement('li');   // 1. create
li.textContent = 'New item!';              // 2. configure
list.appendChild(li);                      // 3. append (at the end)
list.prepend(li);                          //    or at the start

Live demo - build a list dynamically

    Key Points

    • document.createElement('tag') makes an element not yet on the page.
    • Configure it first, then append.
    • appendChild adds at the end, prepend at the start.
