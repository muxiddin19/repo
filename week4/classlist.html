classList - Styling with JavaScript

Define how a class looks in CSS, then let JavaScript add and remove it with classList: add(), remove(), toggle(), contains().

JavaScript
box.classList.add('highlighted');
box.classList.remove('highlighted');
box.classList.toggle('rounded');
box.classList.contains('active');   // true / false

Key Points

  • add adds a class (no duplicates).
  • remove removes it (safe if absent).
  • toggle adds if missing, removes if present.
  • contains returns true/false.
