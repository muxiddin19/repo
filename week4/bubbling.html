Event Bubbling & Delegation

A click on a child also fires on every parent, from the target up to the document: this is bubbling. Delegation uses it: put one listener on the parent and check e.target. It even works for elements added later.

JavaScript
// one listener on the parent handles every button
list.addEventListener('click', (e) => {
  if (e.target.matches('button')) {
    e.target.textContent = 'Clicked!';
  }
});

Key Points

  • Events bubble up from the target through all parents.
  • Delegation = one listener on the parent, use e.target.
  • It works for elements added dynamically.
  • e.target.matches('.cls') tests the clicked element.
