textContent - Reading & Writing Text

textContent reads or sets the plain text of an element. HTML tags in the string are shown literally, never parsed, so it is the safe way to insert user input.

JavaScript
const msg = document.getElementById('msg');
console.log(msg.textContent);          // READ
msg.textContent = 'Welcome!';          // WRITE
msg.textContent = '<b>Not bold</b>';   // shown as plain text

Key Points

  • element.textContent reads the text inside an element.
  • Setting it replaces all content of the element.
  • Tags in the string are shown as text, not parsed as HTML.
  • Use it whenever you insert user input.
