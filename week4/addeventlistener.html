addEventListener

addEventListener(event, callback) tells the browser: when this happens on this element, run this function. Common events: click, input, keydown, submit, mouseover.

JavaScript
let count = 0;
btn.addEventListener('click', () => {
  count++;
  display.textContent = count;
});
input.addEventListener('input', () => {
  echo.textContent = input.value;
});
