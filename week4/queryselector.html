querySelector & querySelectorAll

querySelector() returns the first element matching a CSS selector. querySelectorAll() returns all matches as a NodeList you can loop with forEach.

JavaScript
const first = document.querySelector('li');
const one   = document.querySelector('#special');
const all   = document.querySelectorAll('.citrus');

all.forEach(item => {
  item.classList.add('hit');
});

Key Points

  • querySelector() returns the first match or null.
  • querySelectorAll() returns a NodeList of all matches (may be empty).
  • Any valid CSS selector works: .class, #id, tag, ul > li.
