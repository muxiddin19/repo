Removing Elements

element.remove() deletes an element from the DOM. Combined with delegation and e.target.closest('li'), one listener can remove any item.

JavaScript
list.addEventListener('click', (e) => {
  if (e.target.matches('.rm-btn')) {
    e.target.closest('li').remove();
  }
});

Demo - click Remove to delete items

    Key Points

    • element.remove() removes it from the DOM.
    • closest('li') finds the nearest matching ancestor.
    • Delegation lets one listener serve every item, even restored ones.
