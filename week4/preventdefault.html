e.preventDefault()

Forms reload the page on submit and links navigate away. e.preventDefault() cancels that default so your JavaScript can handle the event instead.

JavaScript
form.addEventListener('submit', (e) => {
  e.preventDefault();   // stops the page reload
  const value = input.value;
  result.textContent = 'Got: ' + value;
});

Key Points

  • e.preventDefault() stops the browser default action.
  • Use it on submit to validate without reloading.
  • Use it on link clicks to stop navigation.
  • Call it first in the handler.
