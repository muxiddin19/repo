08

The Event Object (e)

The browser passes an event object to your callback. e.type is the event name, e.target is the element that triggered it, and e.key is the pressed key for keyboard events.

JavaScript
btn.addEventListener('click', (e) => {
  console.log(e.type);       // 'click'
  console.log(e.target.id);  // id of clicked element
});
input.addEventListener('keydown', (e) => {
  console.log(e.key);        // 'a', 'Enter', ...
});

Event explorer - click or type

Key Points

  • The event object is passed automatically as the first argument.
  • e.type: event name.
  • e.target: element that triggered the event.
  • e.key: key pressed (keyboard events).
