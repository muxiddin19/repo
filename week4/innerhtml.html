innerHTML - Power & Danger

innerHTML reads or sets the HTML inside an element and parses tags. That is powerful but dangerous: putting user input into it allows XSS (injected scripts). Use textContent for anything a user typed.

JavaScript
box.innerHTML = '<strong>Bold</strong> text';   // OK: your own content

box.innerHTML = userInput;     // DANGER: XSS risk
box.textContent = userInput;   // SAFE: tags shown as text

Key Points

  • innerHTML parses and renders HTML tags.
  • textContent treats everything as plain text.
  • Never put user input into innerHTML (XSS).
  • Use innerHTML only for content you control.
