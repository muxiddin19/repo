What is the DOM?

The browser reads your HTML and builds a tree of objects in memory called the DOM (Document Object Model). Every tag becomes a node that JavaScript can read and change. document is the root of the tree.

JavaScript
const sample = document.getElementById('sample');
console.log(sample.children);        // child elements
console.log(sample.parentElement);   // its parent
document.getElementById('title').textContent = 'Changed!';

Key Points

  • DOM = the browser's in-memory tree of the page.
  • Every HTML tag becomes a node (object) JavaScript can access.
  • document is the root and starting point for all DOM access.
  • Changing the DOM updates the page without reloading.
