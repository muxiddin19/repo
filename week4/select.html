Selecting Elements

getElementById() finds one element by its id and returns the element object, or null if nothing matches. IDs must be unique on the page.

JavaScript
const heading = document.getElementById('greeting');
heading.textContent = 'Hello, class!';
heading.style.color = 'blue';

Key Points

  • getElementById('id') returns one element or null.
  • The element has properties such as .textContent, .style, .classList.
  • IDs must be unique on the page.
