01

What is the DOM?

Beginner

When a browser loads an HTML file, it reads it and builds a tree of objects in memory. This tree is called the DOM — Document Object Model. Every HTML tag becomes a node (an object) in the tree, and JavaScript can read and change any node.

Think of the DOM as a living map of the page. You write HTML once; the DOM lets JavaScript update the page at any time — without reloading.

Visual — The DOM Tree

This HTML file becomes this tree in memory:

HTML file
<html> <head> <title>My Page</title> </head> <body> <h1 id="title">Hello</h1> <p>World</p> </body> </html>
DOM Tree in memory
document └── html ├── head │ └── title "My Page" └── body ├── h1 id="title" │ └── "Hello" └── p └── "World"
✅
JavaScript uses document (the root object) to access any part of this tree. Change a node → the page updates instantly.

Key Points

  • DOM = Document Object Model — the browser's in-memory tree of the page.
  • Every HTML tag becomes a node (object) JavaScript can access.
  • document is the root — the starting point for all DOM access.
  • Changing the DOM updates the page without reloading.
02

Selecting Elements

Beginner

Before you can change anything on the page, you need to select it. JavaScript has several ways to grab elements from the DOM.

The oldest (but still used) method is getElementById() — it finds one element by its id attribute. It returns the element object, or null if nothing matches.

JavaScript
// Grab the element with id="greeting" const heading = document.getElementById('greeting'); // Now 'heading' is the actual DOM element — you can change it heading.textContent = 'Hello, class!'; heading.style.color = 'blue';

Key Points

  • getElementById('id') returns one element (or null).
  • The returned object has properties: .textContent, .style, .classList, etc.
  • IDs must be unique on the page — each getElementById call finds at most one element.
03

querySelector & querySelectorAll

Beginner

Modern JavaScript uses CSS selector syntax to find elements. querySelector() returns the first matching element; querySelectorAll() returns all matching elements as a NodeList (like an array).

This is powerful — any CSS selector you know works here: .class, #id, tag, tag.class, [attr], etc.

JavaScript
// querySelector — returns FIRST match (or null) const btn = document.querySelector('button'); const title = document.querySelector('#main-title'); const card = document.querySelector('.card.active'); // querySelectorAll — returns ALL matches (NodeList) const allBtns = document.querySelectorAll('button'); const items = document.querySelectorAll('.list-item'); // Loop through all results items.forEach(item => { item.style.color = 'blue'; });

Visual — Selector Cheat Sheet

'p'

'.myClass'

'li.active'
<li> tags that also have class="active"
'ul > li'
Direct <li> children of <ul>
'[type="text"]'
Inputs with type="text"

Key Points

  • querySelector() → first match only (or null).
  • querySelectorAll() → NodeList of ALL matches (may be empty).
  • Use .forEach() to loop through a NodeList.
  • Any valid CSS selector works as the argument.
04

textContent — Reading & Writing Text

Beginner

textContent reads or sets the plain text content of an element. When you set it, any HTML tags in the string are treated as literal characters — not as HTML. This makes it the safe way to insert user-provided text.

JavaScript
const title = document.querySelector('#title'); // READ the current text console.log(title.textContent); // "Hello" // WRITE new text title.textContent = 'Welcome to Web Programming!'; // HTML tags are treated as plain text (safe!) title.textContent = '<b>This will NOT be bold</b>'; // Page shows: <b>This will NOT be bold</b>
Live Editor — edit and run

Key Points

  • element.textContent reads the text inside an element.
  • Setting textContent replaces ALL text inside the element.
  • HTML tags in the new string are shown as text — not parsed as HTML.
  • Use textContent whenever inserting user input — it's safe.
05

innerHTML — Power & Danger ⚠️

Intermediate

innerHTML reads or sets the HTML inside an element. Unlike textContent, it parses and renders HTML tags — so <b> becomes bold, <img> loads an image, etc.

The danger: if you set innerHTML with user-provided text, an attacker can inject malicious JavaScript (XSS — Cross-Site Scripting). This is one of the most common web vulnerabilities.

JavaScript
const box = document.querySelector('#box'); // ✅ OK — you control the content (no user input) box.innerHTML = '<strong>Bold</strong> and <em>italic</em>'; // ❌ DANGER — never put user input directly into innerHTML! const userInput = prompt('Type something:'); box.innerHTML = userInput; // attacker types: <img src=x onerror="alert('hacked!')"> // ✅ Safe alternative for user input: box.textContent = userInput; // tags shown as text, not executed

If a user types <img src=x onerror="stealCookies()"> and you put that in innerHTML, their script runs. Always use textContent for user input.

Key Points

  • innerHTML reads/writes HTML markup — tags are parsed and rendered.
  • textContent treats everything as plain text — tags show literally.
  • Never put user input directly into innerHTML — XSS risk.
  • Use innerHTML only when YOU control the content (hardcoded templates).
06

classList — Styling with JavaScript

Beginner

classList is how JavaScript toggles visual styles without touching style directly. You define classes in CSS, then add/remove them with JS. The four methods: add(), remove(), toggle(), contains().

JavaScript
const box = document.querySelector('.card'); box.classList.add('highlighted'); // adds class box.classList.remove('highlighted'); // removes class box.classList.toggle('dark'); // adds if absent, removes if present box.classList.contains('active'); // returns true/false // CSS controls what the class LOOKS like: /* .highlighted { background: yellow; font-weight: bold; } .dark { background: #1a2340; color: #fff; } */

Key Points

  • classList.add('x') — adds class x (no duplicates).
  • classList.remove('x') — removes class x (safe if absent).
  • classList.toggle('x') — adds if missing, removes if present.
  • classList.contains('x') — returns true / false.
  • Let CSS define what the class looks like; let JS control when it's applied.
07

addEventListener

Beginner

addEventListener() is the modern way to listen for events. You tell the browser: "when this thing happens on this element, call this function." Common events: 'click', 'keydown', 'input', 'submit', 'mouseover'.

JavaScript
const btn = document.querySelector('#my-btn'); // Syntax: element.addEventListener(eventName, callback) btn.addEventListener('click', function() { console.log('Button was clicked!'); }); // Arrow function — shorter syntax, same effect btn.addEventListener('click', () => { console.log('Also clicked!'); }); // 'input' event — fires every time the value changes const inp = document.querySelector('input'); inp.addEventListener('input', () => { console.log('Input value: ', inp.value); });

The code that makes this work:
let count = 0; const btn = document.querySelector('#count-btn'); btn.addEventListener('click', () => { count++; document.querySelector('#count-display').textContent = count; });

Key Points

  • addEventListener(event, callback) — attaches a listener to an element.
  • Common events: 'click', 'input', 'keydown', 'submit', 'mouseover'.
  • You can add multiple listeners to the same element for different events.
  • The callback function runs every time the event fires.
08

The Event Object (e)

Intermediate

When an event fires, the browser automatically passes an event object to your callback. Name it e or event. It contains details about what happened: which element was clicked (e.target), which key was pressed (e.key), mouse position, and more.

JavaScript
// 'e' (or 'event') is the event object passed automatically btn.addEventListener('click', (e) => { console.log(e.type); // 'click' console.log(e.target); // the element that was clicked console.log(e.target.id); // its id attribute }); // Keyboard events have e.key document.addEventListener('keydown', (e) => { console.log(e.key); // 'Enter', 'a', 'ArrowUp' ... if (e.key === 'Enter') sendMessage(); });

Key Points

  • The event object is automatically passed to your callback as the first argument.
  • e.type — event name ('click', 'keydown', etc.)
  • e.target — the exact element that triggered the event.
  • e.key — the key pressed (for keyboard events).
09

e.preventDefault()

Intermediate

Some elements have built-in default browser behavior: a form submits and reloads the page, a link navigates to a URL, right-click opens a context menu. e.preventDefault() stops the browser's default action so your JavaScript can handle it instead.

JavaScript
const form = document.querySelector('#login-form'); form.addEventListener('submit', (e) => { e.preventDefault(); // ← stops the page reload! // Now validate and handle the form with JavaScript const email = document.querySelector('#email').value; if (!email.includes('@')) { showError('Please enter a valid email.'); } else { loginUser(email); } });
❌ Without preventDefault
✅ With preventDefault

Key Points

  • e.preventDefault() stops the browser's default action.
  • Use on forms ('submit') to handle validation without page reload.
  • Use on links ('click') to prevent navigation.
  • Call it as the first line of your handler so the default never fires.

Event Bubbling & Delegation

Intermediate

When you click a button, the click event doesn't stop there — it bubbles up through all parent elements to the document. A click on the button also fires click events on its parent div, then body, then html, then document.

Event delegation is a pattern that uses bubbling to your advantage: instead of adding a listener to every child element, add one listener to the parent. Use e.target to know which child was clicked.

JavaScript — Event Delegation
// ❌ Without delegation — a listener on EVERY button document.querySelectorAll('button').forEach(btn => { btn.addEventListener('click', handleClick); }); // Problem: new buttons added later won't have a listener! // ✅ With delegation — ONE listener on the parent const list = document.querySelector('#todo-list'); list.addEventListener('click', (e) => { // e.target is the element that was actually clicked if (e.target.matches('.delete-btn')) { e.target.parentElement.remove(); } }); // Works for existing AND future list items!

Key Points

  • Events bubble up — a click on a child also fires on all its parents.
  • Event delegation = one listener on the parent, check e.target to know which child.
  • Delegation works for dynamically added elements (existing listeners don't).
  • e.target.matches('.class') checks if the clicked element matches a CSS selector.
11

createElement & appendChild

Intermediate

JavaScript can create new HTML elements from scratch and insert them into the page. The 3-step pattern: create → configure → append.

JavaScript
// Step 1: Create const li = document.createElement('li'); // Step 2: Configure li.textContent = 'New item!'; li.classList.add('list-item'); // Step 3: Append to the DOM const ul = document.querySelector('#my-list'); ul.appendChild(li); // adds at the END // Alternative: prepend (adds at the START) ul.prepend(li); // insertAdjacentHTML — faster for HTML strings ul.insertAdjacentHTML('beforeend', '<li>Another item</li>');

Key Points

  • document.createElement('tag') — creates an element (not yet in the DOM).
  • Configure first (textContent, classList, attributes), then append.
  • parent.appendChild(el) — adds at the end.
  • parent.prepend(el) — adds at the start.
  • insertAdjacentHTML('beforeend', html) — faster for HTML strings.
12

Removing Elements

Beginner

Elements can be removed from the DOM with .remove() — the simplest modern method. The element simply disappears from the page.

JavaScript
// Select and remove an element const item = document.querySelector('.to-delete'); item.remove(); // gone! // Remove when a delete button is clicked (inside list item) const list = document.querySelector('#my-list'); list.addEventListener('click', (e) => { if (e.target.matches('.delete-btn')) { e.target.closest('li').remove(); // remove the parent li } });

Key Points

  • element.remove() — removes the element from the DOM.
  • e.target.closest('li') — finds the nearest ancestor matching a selector (useful in delegation).
  • Removed elements can still be held in JS variables and re-added later.

Intermediate

  • Use createElement to build each list item
  • Add a "✕" delete button inside each item
  • Listen for 'keydown' on input: add item when e.key === 'Enter'
  • Clear the input after adding (input.value = '')
  • Use event delegation on the list for delete buttons
Hint: To build a list item: const li = document.createElement('li'); li.className = 'todo-item'; Then use li.innerHTML = `<span>${text}</span><button class="del-btn">✕</button>`; For deletion use delegation: check e.target.classList.contains('del-btn') then e.target.closest('li').remove().

const input = document.querySelector('#todo-input'); const addBtn = document.querySelector('#add-btn'); const list = document.querySelector('#todo-list'); const emptyMsg = document.querySelector('#empty-msg'); function updateEmpty() { emptyMsg.style.display = list.children.length === 0 ? Live Search Filter (Advanced)

Advanced
Task: Build a real-time search filter. As the user types, show only the items that match the search text. No page reload, no button — filter as you type using the 'input' event.
  • Listen for 'input' event on the search box
  • Get e.target.value.toLowerCase() as the search term
  • Use querySelectorAll('.student') to get all student rows
  • For each: if name includes the term, show it; otherwise hide it (style.display)
  • BONUS: highlight the matching text with innerHTML (it's your content — safe here)
Hint: Get the name from the data attribute: student.dataset.name.toLowerCase(). Then: student.style.display = name.includes(term) ? '' : 'none'; For the bonus highlight, store the original text in data-name and use: student.innerHTML = original.replace(term, '<mark>' + term + '</mark>')
Solution
const searchInp = document.querySelector('#search'); const students = document.querySelectorAll('.student'); const noResults = document.querySelector('#no-results'); searchInp.addEventListener('input', (e) => { const term = e.target.value.toLowerCase(); let visible = 0; students.forEach(s => { const name = s.dataset.name.toLowerCase(); if (name.includes(term)) { s.style.display = ''; visible++; // Bonus: highlight match if (term) { const rx = new RegExp(`(${term})`, 'gi'); s.innerHTML = s.dataset.name.replace(rx, '<mark>$1</mark>') + ' — ' + s.textContent.split('—')[1].trim(); } else { s.textContent = s.dataset.name + ' — ' + s.textContent.split('—')[1].trim(); } } else { s.style.display = 'none'; } }); noResults.style.display = visible === 0 ? 'block' : 'none'; });
